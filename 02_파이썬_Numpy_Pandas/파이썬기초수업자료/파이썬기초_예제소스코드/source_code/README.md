# 파이썬 기초 3일 과정 — 예제 소스코드

강의 자료 본문에 나오는 모든 예제 코드입니다.
VSCode에서 이 폴더(`source_code`)를 열고, 원하는 파일을 실행해 보세요.

## 폴더 구성

```
source_code/
├── day1/            1일차 예제 40개 (변수·연산자·문자열·입출력)
├── day2/            2일차 예제 60개 (조건문·반복문·자료구조·컴프리헨션)
├── day3/            3일차 예제 40개 (함수·파일·예외처리·클래스)
└── final_project/   종합 실습 (데이터셋 라벨 검증 도구)
```

## 파일 이름 규칙

```
d2_dict_03.py     → Day2 · 딕셔너리 · 기본예제 3번
d2_dict_a3.py     → Day2 · 딕셔너리 · 실무예제 3번 (a = applied)
```

| 구분 | 표시 | 내용 |
|---|---|---|
| 기본 예제 | `_01` ~ `_05` | 문법 자체에 익숙해지기 위한 예제 |
| 실무 예제 | `_a1` ~ `_a5` | 실제 프로젝트에서 쓰이는 형태의 예제 |

### 주제별 약어

| 약어 | 주제 | 약어 | 주제 |
|---|---|---|---|
| `var` | 변수와 자료형 | `dict` | 딕셔너리 |
| `op` | 연산자 | `ts` | 튜플과 집합 |
| `str` | 문자열 | `comp` | 리스트 컴프리헨션 |
| `io` | 입력과 출력 | `func` | 함수 |
| `if` | 조건문 | `file` | 파일 입출력 |
| `loop` | 반복문 | `exc` | 예외처리 |
| `list` | 리스트 | `cls` | 클래스 |

## 실행 방법

### VSCode에서 실행
1. VSCode에서 `source_code` 폴더 열기 (파일 → 폴더 열기)
2. 실행할 `.py` 파일 클릭
3. 오른쪽 위 **▶ 실행 버튼** 클릭

### 터미널에서 실행
```bash
cd day1
python d1_var_01.py
```

## 주의사항

- 일부 예제(`d1_io_*`)는 `input()`으로 값을 입력받습니다. 터미널에 값을 입력하고 Enter를 누르세요.
- 파일을 만드는 예제(`d3_file_*`, `d3_exc_*`)는 **실행한 위치에 파일과 폴더를 생성**합니다.
  정리하고 싶다면 생성된 `output/`, `labels/`, `ds/`, `dataset/` 폴더와 `.txt`, `.csv`, `.json` 파일을 삭제하면 됩니다.
- 모든 예제는 Python 3.8 이상에서 동작합니다.

## 학습 팁

코드를 그냥 실행만 하지 말고, **값을 바꿔가며 결과가 어떻게 달라지는지** 확인해 보세요.
가장 많이 배우게 되는 순간은 "이렇게 바꾸면 어떻게 될까?"를 직접 시험해 볼 때입니다.

예를 들어 `d2_loop_a1.py`에서 `threshold = 0.7`을 `0.5`나 `0.9`로 바꿔보면
채택/제외 건수가 어떻게 달라지는지 바로 알 수 있습니다.
