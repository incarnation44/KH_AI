DAY 2

조건문 · 반복문 · 자료구조

여러 개의 값을 한 번에 판단하고, 반복 처리하고, 구조화해서 저장하는 방법을 배웁니다.

2일차에서 배우는 것

1일차에서는 값 하나를 저장하고 계산했습니다. 2일차에서는 여러 개의 값을 한꺼번에 다루는 방법을 배웁니다. 이 두 가지가 결합되는 순간, 파이썬은 비로소 "사람 대신 일해주는 도구"가 됩니다.

💡 오늘의 핵심 감각

"이 작업을 100번 해야 한다면?"이라는 질문을 계속 던져보세요. 같은 코드를 복사·붙여넣기 하고 있다면 반복문을 써야 한다는 신호이고, 비슷한 변수를 여러 개 만들고 있다면 리스트나 딕셔너리를 써야 한다는 신호입니다.

조건문 — if / elif / else

조건문은 "상황에 따라 다르게 행동하기"입니다. 검출된 이물이 어떤 종류인지 판정하거나, 신뢰도에 따라 등급을 나누거나, 데이터가 정상인지 검사하는 일 모두 조건문으로 처리합니다.

기본 구조

구조
if 조건1:
    조건1이 참일 때 실행
elif 조건2:
    조건1은 거짓이고 조건2가 참일 때 실행
else:
    위 조건이 모두 거짓일 때 실행
📌 파이썬은 들여쓰기로 블록을 구분합니다

다른 언어가 중괄호 { }로 묶는 부분을, 파이썬은 들여쓰기로 표현합니다. 콜론(:) 다음 줄부터 스페이스 4칸 들여 쓴 부분이 "조건이 참일 때 실행할 코드"입니다. 들여쓰기가 맞지 않으면 IndentationError가 발생하므로, 탭과 스페이스를 섞어 쓰지 않도록 주의합니다.

⚠️ elif는 "앞 조건이 모두 거짓일 때만" 검사합니다

if를 여러 번 나열하면 모든 조건을 각각 검사하지만, elif는 위에서부터 순서대로 보다가 처음 맞는 곳에서 멈춥니다. 등급을 나눌 때 if conf >= 0.9 다음에 elif conf >= 0.7을 쓰면 0.95는 첫 조건에서 걸려 "상"이 되고, 두 번째는 검사하지 않습니다.

기본 예제 문법 자체에 익숙해지기

기본 1가장 단순한 if

d2_if_01.py
# [목적] 조건이 참일 때만 코드를 실행하는 기본 형태
# [설명] 콜론(:)과 들여쓰기가 조건문의 필수 요소입니다.

score = 85

if score >= 60:
    print("합격입니다")

print("검사 종료")     # 들여쓰기 없음 = 조건과 무관하게 항상 실행
실행 결과
합격입니다
검사 종료

마지막 print는 들여쓰기가 없으므로 조건문 밖에 있습니다. 들여쓰기 하나가 "조건 안/밖"을 가르므로 눈으로 정렬을 꼭 확인하는 습관이 필요합니다.

else는 "나머지 모든 경우"를 뜻하므로 조건을 따로 적지 않습니다. 두 갈래로만 나뉘는 판정에는 이 형태가 가장 읽기 쉽습니다.

기본 3elif로 여러 갈래 나누기

d2_if_03.py
# [목적] 세 가지 이상의 경우를 순서대로 판정한다
# [설명] 위에서부터 검사하다가 처음 맞는 곳에서 멈춥니다.

score = 78

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"점수 {score} -> 등급 {grade}")
실행 결과
점수 78 -> 등급 C

구간을 나눌 때는 큰 값부터 순서대로 쓰는 것이 요령입니다. 78은 90·80을 통과하지 못하고 70에서 걸려 "C"가 됩니다. 순서를 반대로 쓰면 모든 점수가 첫 조건에 걸려버립니다.

기본 4여러 조건을 and · or로 묶기

입장 가능
주말입니다
주말입니다 (in 버전)

같은 변수를 여러 값과 비교할 때는 or를 반복하는 대신 in [목록]을 쓰면 훨씬 짧고 읽기 좋습니다. 값이 늘어나도 목록만 고치면 됩니다.

기본 5중첩 조건문과 조건부 표현식

값A if 조건 else 값B는 간단한 두 갈래 선택을 한 줄로 처리합니다. 다만 조건이 복잡해지면 오히려 읽기 어려우므로, 단순한 경우에만 사용하는 것이 좋습니다.

실무 2검출 결과 OK/NG 판정 로직

d2_if_a2.py
# [목적] 제품검사 시스템의 최종 판정 로직을 구현한다
# [설명] 교과 14 프로젝트의 핵심 판정부에 해당합니다.

detected_count = 2          # 검출된 이물 개수
max_confidence = 0.93       # 가장 확신하는 검출의 신뢰도
threshold = 0.7

if detected_count == 0:
    verdict = "OK"
    reason = "이물 없음"
elif max_confidence < threshold:
    verdict = "보류"
    reason = f"검출되었으나 신뢰도 낮음 ({max_confidence:.0%})"
else:
    verdict = "NG"
    reason = f"이물 {detected_count}건 검출 (최대 신뢰도 {max_confidence:.0%})"

print(f"판정: {verdict}")
print(f"사유: {reason}")
실행 결과
판정: NG
사유: 이물 2건 검출 (최대 신뢰도 93%)

판정 결과만 내는 것이 아니라 사유까지 함께 남기는 것이 실무 시스템의 조건입니다. 나중에 오판정을 분석할 때 "왜 이렇게 판정했는지" 추적할 수 있어야 하기 때문입니다.

실무 3라벨 데이터 유효성 검사

d2_if_a3.py
# [목적] 라벨 한 줄이 올바른 형식인지 여러 단계로 검사한다
# [설명] 데이터 품질 평가(10점) 항목과 직결되는 작업입니다.

line = "3 0.42 0.35 1.20 0.08"      # 세 번째 값이 1을 초과 -> 오류
parts = line.split()

if len(parts) != 5:
    result = "오류: 컬럼이 5개가 아님"
elif not parts[0].isdigit():
    result = "오류: 클래스ID가 숫자가 아님"
elif int(parts[0]) not in [1, 2, 3, 5, 6]:
    result = "오류: 등록되지 않은 클래스ID"
else:
    coords = [float(p) for p in parts[1:]]
    if min(coords) < 0 or max(coords) > 1:
        result = "오류: 좌표가 0~1 범위를 벗어남"
    else:
        result = "정상"

print(f"검사 대상: {line}")
print(f"결과: {result}")
실행 결과
검사 대상: 3 0.42 0.35 1.20 0.08
결과: 오류: 좌표가 0~1 범위를 벗어남

검사를 순서대로 배치한 점이 중요합니다. 컬럼 개수를 먼저 확인해야 parts[0]에 접근할 때 오류가 안 나고, 숫자인지 확인해야 int()가 안전합니다. 검사 순서 자체가 방어 로직입니다.

실무 4성능 목표 달성 여부 종합 판정

d2_if_a4.py
# [목적] 프로젝트 목표 성능 3가지를 모두 검사해 종합 판정한다

print(f"속도          : {fps:.1f} FPS -> {'통과' if pass_fps else '미달'}")
print("-" * 34)

if pass_ap and pass_acc and pass_fps:
    print("종합 판정: 전 항목 목표 달성")
elif pass_ap and pass_acc:
    print("종합 판정: 정확도는 달성, 속도 최적화 필요")
else:
    print("종합 판정: 모델 성능 개선 필요")

반복문 — for / while

수천 장의 이미지를 손으로 하나씩 처리할 수는 없습니다. 반복문은 "같은 작업을 자동으로 여러 번" 실행하게 해주는, 프로그래밍의 가장 강력한 도구입니다.

forwhile
쓰는 상황처리할 목록이 정해져 있을 때조건이 만족되는 동안 계속
예시파일 100개를 하나씩 검사올바른 값이 입력될 때까지 반복
끝나는 시점목록을 다 돌면 자동 종료조건이 거짓이 되어야 종료

반복 제어 키워드

키워드하는 일
break반복을 즉시 완전히 중단
continue이번 회차만 건너뛰고 다음으로
range(a, b, c)a부터 b 직전까지 c씩 증가하는 숫자 생성
enumerate(목록)순번과 값을 함께 꺼냄

⚠️ while 무한 루프 주의

while의 조건이 영원히 참이면 프로그램이 멈추지 않습니다. 반복 안에서 조건에 영향을 주는 값이 반드시 바뀌는지 확인하세요. 실행이 멈추지 않을 때는 터미널에서 Ctrl + C로 강제 종료할 수 있습니다.

기본 1for로 목록 순회하기

d2_loop_01.py
# [목적] 리스트의 값을 하나씩 꺼내 반복 처리한다
# [설명] "for 변수 in 목록:" 형태가 기본입니다.

fruits = ["사과", "바나나", "딸기"]

for fruit in fruits:
    print("과일:", fruit)

리스트 — 여러 값을 순서대로 담기

리스트는 대괄호 [ ]로 여러 값을 순서대로 담는 상자입니다. bbox 좌표들, 파일명 목록, 신뢰도 값들처럼 "같은 종류의 값이 여러 개"일 때 사용합니다.

자주 쓰는 리스트 메서드

메서드하는 일
.append(값)맨 뒤에 값 하나 추가
.extend(목록)다른 리스트의 값들을 모두 추가
.insert(위치, 값)지정한 위치에 값 끼워 넣기
.remove(값)해당 값을 가진 첫 항목 삭제
.pop(위치)해당 위치 값을 꺼내면서 삭제
.sort()리스트 자체를 정렬 (원본 변경)
sorted(리스트)정렬된 새 리스트를 반환 (원본 유지)
.count(값)해당 값이 몇 개 있는지
.index(값)해당 값이 몇 번째에 있는지
📌 sort()와 sorted()의 차이

리스트.sort()는 원본을 직접 바꾸고 아무것도 돌려주지 않습니다. sorted(리스트)는 원본은 그대로 두고 정렬된 새 리스트를 만들어 줍니다. 원본 순서를 유지해야 할 때는 반드시 sorted()를 쓰세요.

딕셔너리 — 이름표(key)로 값 찾기

리스트가 순서(번호)로 값을 찾는다면, 딕셔너리는 이름표(key)로 값을 찾습니다. 중괄호 { } 안에 key: value 쌍을 적습니다.

📌 언제 리스트, 언제 딕셔너리?

리스트: 같은 종류의 값이 여러 개 나열될 때 (신뢰도 5개, 파일명 100개)
딕셔너리: 서로 다른 성격의 값이 하나의 대상을 설명할 때 (한 검출의 클래스·좌표·신뢰도)
실무에서는 딕셔너리를 담은 리스트 형태가 가장 많이 쓰입니다.

자주 쓰는 딕셔너리 메서드

메서드하는 일
.keys()모든 key 목록
.values()모든 value 목록
.items()(key, value) 쌍 목록 — 순회할 때 사용
.get(key, 기본값)key가 없어도 오류 없이 기본값 반환
key in 딕셔너리해당 key가 있는지 확인
del 딕셔너리[key]항목 삭제

# [목적] 여러 검출 결과를 파일 단위로 묶어 정리한다
# [설명] 이미지 한 장에 여러 이물이 있을 때 필요한 처리입니다.

detections = [
    {"file": "img_001.jpg", "class_id": 1, "conf": 0.92},
    {"file": "img_002.jpg", "class_id": 6, "conf": 0.55},
    {"file": "img_001.jpg", "class_id": 3, "conf": 0.81},
    {"file": "img_003.jpg", "class_id": 2, "conf": 0.88},
    {"file": "img_001.jpg", "class_id": 6, "conf": 0.76},
]

grouped = {}
for d in detections:
    fname = d["file"]
    if fname not in grouped:
        grouped[fname] = []
    grouped[fname].append(d)

for fname in sorted(grouped):
    items = grouped[fname]
    max_conf = max(x["conf"] for x in items)
    verdict = "NG" if max_conf >= 0.7 else "보류"
    print(f"{fname}: 검출 {len(items)}건, 최고신뢰도 {max_conf:.0%} -> {verdict}")

리스트 컴프리헨션 — 한 줄로 리스트 만들기

"반복문으로 새 리스트를 만드는 코드"를 한 줄로 압축한 문법입니다. 처음엔 낯설지만 실무 코드에 매우 자주 등장하므로, 먼저 읽을 줄 아는 것부터 시작하면 됩니다.

구조
[결과값 for 항목 in 목록 if 조건]
  ↑ 무엇을 담을지     ↑ 어디서 꺼낼지      ↑ 어떤 것만 (생략 가능)

읽는 순서는 가운데 → 오른쪽 → 왼쪽입니다. "목록에서 항목을 하나씩 꺼내(for), 조건에 맞는 것만(if), 결과값 형태로 담는다"고 소리 내어 읽어보면 이해가 빠릅니다.

💡 딕셔너리·집합도 같은 방식으로

{k: v for ...} → 딕셔너리 컴프리헨션 · {x for ...} → 집합 컴프리헨션
대괄호를 중괄호로 바꾸기만 하면 됩니다.

⚠️ 한 줄에 다 넣으려 하지 마세요

조건이 두 개 이상 겹치거나 처리가 복잡해지면 컴프리헨션이 오히려 읽기 어려워집니다. 그럴 때는 평범한 반복문으로 여러 줄에 나눠 쓰는 것이 더 좋은 코드입니다.

# [설명] 딕셔너리 컴프리헨션과 count()의 조합입니다.

detected = [1, 6, 1, 3, 1, 6, 2, 1, 3, 6, 1, 5]
CLASS_MAP = {1: "나뭇잎류", 2: "플라스틱류", 3: "나뭇가지류",
             5: "병해·갈변", 6: "파·고추"}

# 집합으로 고유 클래스를 뽑고, count로 개수를 센다
counts = {cid: detected.count(cid) for cid in sorted(set(detected))}
print("집계:", counts)

total = len(detected)
report = [f"{CLASS_MAP[cid]}: {n}건 ({n/total:.0%})"
          for cid, n in counts.items()]

print("\n=== 클래스 분포 ===")
for line in report:
    print(" -", line)

# 부족한 클래스 찾기 (전체의 10% 미만)
rare = [CLASS_MAP[cid] for cid, n in counts.items() if n / total < 0.10]
print("\n추가 촬영 권장:", rare)
