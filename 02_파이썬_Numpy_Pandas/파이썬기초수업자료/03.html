3일차에서 배우는 것

2일차까지 배운 것으로도 꽤 많은 일을 할 수 있습니다. 하지만 코드가 길어지면 세 가지 문제가 생깁니다.

문제해결책오늘 배울 내용
같은 코드를 계속 반복해서 쓰게 된다이름 붙여 재사용함수

데이터와 처리 코드가 흩어져 있다하나로 묶기클래스

오늘 배우는 네 가지는 "돌아가는 코드"를 "쓸 만한 도구"로 바꾸는 기술입니다. 마지막 종합 실습에서는 3일 동안 배운 모든 것을 조합해 실제 프로젝트에서 사용할 수 있는 라벨 검증 도구를 완성합니다.

함수 — 반복되는 코드를 이름 붙여 재사용하기

같은 계산을 여러 번 쓰고 있다면 함수로 묶을 때가 된 것입니다. 함수는 "입력을 받아 처리한 뒤 결과를 돌려주는 작은 기계"입니다.

구조
def 함수이름(매개변수1, 매개변수2):
    처리할 코드
    return 돌려줄 값

결과 = 함수이름(값1, 값2)
📌 함수를 쓰면 좋은 세 가지 이유
  • 재사용 — 같은 코드를 여러 번 쓰지 않아도 됩니다
  • 수정이 쉬움 — 계산 방식이 바뀌면 함수 안 한 곳만 고치면 됩니다
  • 읽기 쉬움 — calc_iou(a, b)라는 이름만 봐도 무슨 일을 하는지 알 수 있습니다

매개변수의 여러 형태

형태의미예시
일반 매개변수반드시 값을 넘겨야 함def f(a, b):
기본값 매개변수생략하면 기본값 사용def f(a, b=0.7):
*args개수가 정해지지 않은 값들을 튜플로def f(*items):
**kwargs이름 붙은 값들을 딕셔너리로def f(**opts):
⚠️ return이 없으면 None이 반환됩니다

함수 안에서 print()만 하고 return을 쓰지 않으면, 함수의 결과값은 None입니다. 계산 결과를 다른 곳에서 써야 한다면 반드시 return으로 돌려주어야 합니다.

실무 1bbox 면적과 IOU 계산 함수

d3_func_a1.py
# [목적] 객체검출 평가에 쓰이는 핵심 계산을 함수로 만든다
# [설명] IOU = 겹치는 넓이 / 전체 합친 넓이 (0~1 사이 값)
#        box 형식: [x1, y1, x2, y2] (좌상단, 우하단)

def get_area(box):
    return (box[2] - box[0]) * (box[3] - box[1])

def calc_iou(box_a, box_b):
    # 겹치는 영역의 좌표
    x1 = max(box_a[0], box_b[0])
    y1 = max(box_a[1], box_b[1])
    x2 = min(box_a[2], box_b[2])
    y2 = min(box_a[3], box_b[3])

    inter = max(0, x2 - x1) * max(0, y2 - y1)     # 안 겹치면 0
    union = get_area(box_a) + get_area(box_b) - inter
    return inter / union if union > 0 else 0.0

pred = [50, 50, 150, 150]
truth = [60, 60, 140, 160]

print("예측 면적:", get_area(pred))
print("정답 면적:", get_area(truth))
print(f"IOU: {calc_iou(pred, truth):.3f}")
print("검출 성공(IOU>=0.5)?", calc_iou(pred, truth) >= 0.5)

# 전혀 안 겹치는 경우
far = [500, 500, 600, 600]
print(f"멀리 있는 박스와의 IOU: {calc_iou(pred, far):.3f}")
실행 결과

정답 면적: 8000
IOU: 0.667
검출 성공(IOU>=0.5)? True

# [목적] 정규화 좌표 <-> 픽셀 좌표 변환을 함수로 정리한다
# [설명] 라벨링 툴과 시각화 코드에서 계속 재사용됩니다.

def yolo_to_pixel(cx, cy, w, h, img_w, img_h):
    """YOLO 정규화 좌표를 픽셀 [x1,y1,x2,y2]로 변환"""
    px_w, px_h = w * img_w, h * img_h
    x1 = cx * img_w - px_w / 2
    y1 = cy * img_h - px_h / 2
    return [round(x1), round(y1), round(x1 + px_w), round(y1 + px_h)]

def pixel_to_yolo(x1, y1, x2, y2, img_w, img_h):
    """픽셀 좌표를 YOLO 정규화 좌표로 변환"""
    cx = (x1 + x2) / 2 / img_w
    cy = (y1 + y2) / 2 / img_h
    w = (x2 - x1) / img_w
    h = (y2 - y1) / img_h
    return round(cx, 4), round(cy, 4), round(w, 4), round(h, 4)

IMG_W, IMG_H = 4848, 2704

box = yolo_to_pixel(0.42, 0.35, 0.10, 0.08, IMG_W, IMG_H)
print("YOLO -> 픽셀:", box)

back = pixel_to_yolo(box[0], box[1], box[2], box[3], IMG_W, IMG_H)
print("픽셀 -> YOLO:", back)

# 반올림 때문에 완전히 같지는 않다 -> 오차 범위로 비교해야 한다
original = (0.42, 0.35, 0.10, 0.08)
print("완전히 일치?", back == original)
diffs = [abs(a - b) for a, b in zip(back, original)]
print("항목별 오차:", [round(d, 5) for d in diffs])
print("오차 0.001 이내로 일치?", max(diffs) < 0.001)

# [목적] 여러 조건을 인자로 받아 유연하게 필터링한다
# [설명] 기본값 덕분에 간단히 쓸 수도, 세밀하게 조정할 수도 있습니다.

def filter_detections(detections, min_conf=0.7, min_area=100, valid_classes=None):
    if valid_classes is None:
        valid_classes = [1, 2, 3, 5, 6]

    result = []
    for d in detections:
        area = d["bbox"][2] * d["bbox"][3]
        if d["conf"] < min_conf:
            continue
        if area < min_area:
            continue
        if d["class_id"] not in valid_classes:
            continue
        result.append(d)
    return result

실무 4성능 지표 계산 함수 세트

d3_func_a4.py
# [목적] Precision, Recall, F1을 각각 함수로 만들어 재사용한다
# [설명] 최종 프로젝트 평가 리포트에 그대로 쓰입니다.

def precision(tp, fp):
    return tp / (tp + fp) if (tp + fp) > 0 else 0.0

def recall(tp, fn):
    return tp / (tp + fn) if (tp + fn) > 0 else 0.0

def f1_score(tp, fp, fn):
    p = precision(tp, fp)
    r = recall(tp, fn)
    return 2 * p * r / (p + r) if (p + r) > 0 else 0.0

def print_report(name, tp, fp, fn):
    print(f"[{name}]")
    print(f"  Precision: {precision(tp, fp):.3f}")
    print(f"  Recall   : {recall(tp, fn):.3f}")
    print(f"  F1 Score : {f1_score(tp, fp, fn):.3f}")

print_report("나뭇잎류", tp=85, fp=15, fn=10)
print_report("파·고추", tp=42, fp=28, fn=35)
print_report("데이터없음", tp=0, fp=0, fn=0)

    try:
        return a / b
    except ZeroDivisionError:

def read_label(path):
    try:
        with open(path, "r", encoding="utf-8") as f:
            lines = [ln.strip() for ln in f if ln.strip()]
    except FileNotFoundError:
        print(f"  [경고] 라벨 파일 없음: {path}")
        return []
    except UnicodeDecodeError:
        print(f"  [경고] 인코딩 오류: {path}")
        return []

    for i, line in enumerate(lines, 1):
        try:
            parts = line.split()
            if len(parts) != 5:
                raise ValueError(f"컬럼이 5개가 아님({len(parts)}개)")
            boxes.append({
                "class_id": int(parts[0]),
                "coords": [float(v) for v in parts[1:5]],
            })
        except (ValueError, IndexError) as e:
            print(f"  [경고] {path} {i}번째 줄 형식 오류: {e}")

클래스 — 데이터와 동작을 하나로 묶기

지금까지는 검출 결과를 딕셔너리로 표현했습니다. 클래스를 쓰면 데이터(속성)와 그 데이터로 하는 일(메서드)을 하나의 틀로 묶을 수 있습니다.

📌 클래스는 붕어빵 틀, 인스턴스는 붕어빵

class Detection:은 틀을 만드는 것이고, d = Detection(1, [...], 0.92)는 그 틀로 실제 물건 하나를 찍어내는 것입니다. 틀 하나로 붕어빵을 몇 개든 만들 수 있듯, 클래스 하나로 인스턴스를 얼마든지 만들 수 있습니다.

주요 구성 요소

요소역할
class 이름:클래스 정의 시작. 이름은 첫 글자 대문자가 관례
__init__(self, ...)인스턴스가 만들어질 때 자동 실행. 속성 초기화 담당
self"지금 이 인스턴스 자신". 모든 메서드의 첫 매개변수
self.속성 = 값인스턴스에 데이터를 저장
def 메서드(self):이 클래스가 할 수 있는 동작
__str__(self)print()했을 때 보여줄 문자열 정의
⚠️ self를 빠뜨리지 마세요

메서드의 첫 매개변수는 항상 self여야 하고, 속성에 접근할 때도 self.속성이라고 써야 합니다. self를 빼먹으면 "그냥 지역 변수"가 되어 값이 저장되지 않습니다. 초보자가 가장 많이 하는 실수입니다.

# [목적] 검증 규칙과 결과 집계를 하나의 클래스로 관리한다
# [설명] 설정과 상태를 함께 가지는 도구형 클래스입니다.

class LabelValidator:
    def __init__(self, valid_classes=None):
        self.valid_classes = valid_classes or [1, 2, 3, 5, 6]
        self.errors = []
        self.checked = 0

    def check_line(self, file_name, line_no, line):
        self.checked += 1
        parts = line.split()

        if len(parts) != 5:
            return self._add(file_name, line_no, "컬럼 개수 오류")
        try:
            cid = int(parts[0])
        except ValueError:
            return self._add(file_name, line_no, "클래스ID가 숫자 아님")
        if cid not in self.valid_classes:
            return self._add(file_name, line_no, f"미등록 클래스 {cid}")
        try:
            coords = [float(v) for v in parts[1:]]
        except ValueError:
            return self._add(file_name, line_no, "좌표가 숫자 아님")
        if min(coords) < 0 or max(coords) > 1:
            return self._add(file_name, line_no, "좌표 범위 초과")
        return True

    def _add(self, file_name, line_no, msg):
        self.errors.append({"file": file_name, "line": line_no, "error": msg})
        return False

    def report(self):
        print(f"검사 {self.checked}줄 / 오류 {len(self.errors)}건")
        for e in self.errors:
            print(f"  {e['file']} {e['line']}행: {e['error']}")
        rate = (self.checked - len(self.errors)) / self.checked
        print(f"정상률: {rate:.1%}")

    "img_001.txt": ["1 0.42 0.35 0.10 0.08", "6 0.71 0.60 0.15 0.12"],
    "img_002.txt": ["3 1.20 0.40 0.10 0.10", "abc 0.3 0.3 0.1 0.1"],
    "img_003.txt": ["9 0.50 0.50 0.10 0.10", "2 0.30 0.30"],
}

v = LabelValidator()
for fname, lines in data.items():
    for i, line in enumerate(lines, 1):
        v.check_line(fname, i, line)

v.report()

  img_003.txt 1행: 미등록 클래스 9
  img_003.txt 2행: 컬럼 개수 오류

# [목적] 데이터셋의 파일 목록과 분할, 통계를 한 곳에서 관리한다
# [설명] 실무에서 가장 흔히 만드는 형태의 관리 클래스입니다.

class Dataset:
    def __init__(self, name):
        self.name = name
        self.items = []        # (파일명, 클래스ID) 목록

    def add(self, file_name, class_id):
        self.items.append((file_name, class_id))

    def size(self):
        return len(self.items)

    def class_counts(self):
        counts = {}
        for _, cid in self.items:
            counts[cid] = counts.get(cid, 0) + 1
        return counts

    def split(self, train=0.7, val=0.15):
        n = self.size()
        a, b = int(n * train), int(n * train) + int(n * val)
        return {"train": self.items[:a], "val": self.items[a:b],

class BaseResult:
    def __init__(self, file_name, confidence):
        self.file_name = file_name
        self.confidence = confidence

    def is_confident(self, threshold=0.7):
        return self.confidence >= threshold

    def __str__(self):
        return f"{self.file_name}: {self.summary()}"

    def summary(self):
        return "기본 결과"

class DefectResult(BaseResult):          # BaseResult를 물려받음
    def __init__(self, file_name, confidence, class_name, area):

    def summary(self):

        return f"[{v}] {self.class_name} 면적 {self.area} ({self.confidence:.0%})"

class ActionResult(BaseResult):

        self.action = action
        self.keypoints = keypoints

    def summary(self):
        return f"동작 '{self.action}' 관절 {self.keypoints}개 ({self.confidence:.0%})"

# =========================================================
# 데이터셋 라벨 검증 도구
# [목적] 라벨 파일의 형식 오류를 찾아 CSV 리포트로 정리한다
# [사용] python validate_dataset.py
# =========================================================
import os, glob, csv

VALID_CLASSES = [1, 2, 3, 5, 6]
CLASS_NAMES = {1: "나뭇잎류", 2: "플라스틱류", 3: "나뭇가지류",
               5: "병해·갈변", 6: "파·고추"}


class DatasetValidator:
    def __init__(self, image_dir, label_dir):
        self.image_dir = image_dir
        self.label_dir = label_dir
        self.errors = []          # 발견된 오류 목록
        self.class_counts = {}    # 클래스별 객체 수
        self.total_lines = 0

    # ---------- 한 줄 검사 ----------
    def check_line(self, file_name, line_no, line):
        self.total_lines += 1
        parts = line.split()

        if len(parts) != 5:
            return self._error(file_name, line_no, f"컬럼 {len(parts)}개 (5개여야 함)")

        try:
            class_id = int(parts[0])
        except ValueError:
            return self._error(file_name, line_no, f"클래스ID가 숫자 아님: '{parts[0]}'")

        if class_id not in VALID_CLASSES:
            return self._error(file_name, line_no, f"미등록 클래스: {class_id}")

        try:
            coords = [float(v) for v in parts[1:]]
        except ValueError:
            return self._error(file_name, line_no, "좌표가 숫자 아님")

        if min(coords) < 0 or max(coords) > 1:
            return self._error(file_name, line_no, "좌표가 0~1 범위 초과")

        if coords[2] == 0 or coords[3] == 0:
            return self._error(file_name, line_no, "너비 또는 높이가 0")

        # 정상 -> 클래스 집계
        self.class_counts[class_id] = self.class_counts.get(class_id, 0) + 1
        return True

    def _error(self, file_name, line_no, message):
        self.errors.append({"file": file_name, "line": line_no, "error": message})
        return False

    # ---------- 파일 하나 검사 ----------
    def check_file(self, path):
        name = os.path.basename(path)
        try:
            with open(path, "r", encoding="utf-8") as f:
                lines = [ln.strip() for ln in f if ln.strip()]
        except FileNotFoundError:
            return self._error(name, 0, "파일을 열 수 없음")

        if not lines:
            return self._error(name, 0, "빈 라벨 파일 (객체 없음)")

        for i, line in enumerate(lines, start=1):
            self.check_line(name, i, line)

    # ---------- 이미지-라벨 짝 검사 ----------
    def check_pairs(self):
        images = {os.path.splitext(f)[0]
                  for f in os.listdir(self.image_dir) if f.endswith(".jpg")}
        labels = {os.path.splitext(f)[0]
                  for f in os.listdir(self.label_dir) if f.endswith(".txt")}
        return {
            "matched": sorted(images & labels),
            "no_label": sorted(images - labels),
            "no_image": sorted(labels - images),
        }

    # ---------- 전체 실행 ----------
    def run(self):
        files = sorted(glob.glob(os.path.join(self.label_dir, "*.txt")))
        for path in files:
            self.check_file(path)
        return len(files)

    # ---------- 리포트 ----------
    def print_report(self, file_count, pairs):
        print("=" * 52)
        print("          데이터셋 검증 리포트")
        print("=" * 52)

        print(f"\n[1] 파일 현황")
        print(f"  라벨 파일   : {file_count}개")
        print(f"  검사한 줄   : {self.total_lines}줄")
        print(f"  정상 짝     : {len(pairs['matched'])}건")
        print(f"  라벨 누락   : {len(pairs['no_label'])}건 {pairs['no_label']}")
        print(f"  이미지 누락 : {len(pairs['no_image'])}건 {pairs['no_image']}")

        print(f"\n[2] 오류 현황 : 총 {len(self.errors)}건")
        for e in self.errors:
            print(f"  {e['file']:<16} {e['line']:>3}행  {e['error']}")

        print(f"\n[3] 클래스 분포")
        total = sum(self.class_counts.values())
        if total > 0:
            for cid in sorted(self.class_counts):
                n = self.class_counts[cid]
                bar = "█" * int(n / total * 20)
                name = CLASS_NAMES.get(cid, "?")
                print(f"  {name:<10} {n:>3}개 {bar} {n/total:.0%}")
            missing = set(VALID_CLASSES) - set(self.class_counts)
            if missing:
                print(f"  [주의] 한 번도 등장하지 않은 클래스: {sorted(missing)}")

        ok_rate = (self.total_lines - len(self.errors)) / self.total_lines if self.total_lines else 0
        print(f"\n[4] 종합 : 정상률 {ok_rate:.1%}")
        print("=" * 52)

    def save_csv(self, path="validation_report.csv"):
        if not self.errors:
            print("오류가 없어 리포트를 생성하지 않았습니다.")
            return
        with open(path, "w", encoding="utf-8-sig", newline="") as f:
            w = csv.DictWriter(f, fieldnames=["file", "line", "error"])
            w.writeheader()
            w.writerows(self.errors)
        print(f"오류 {len(self.errors)}건을 {path}에 저장했습니다.")

다음 단계 — Numpy와 Pandas가 필요한 이유

방금 만든 검증 도구는 라벨 파일 5개, 8줄을 검사했습니다. 그런데 실제 프로젝트에서는 이미지 1,000장, 라벨 수천 줄을 다루게 됩니다.

🐢 지금 방식의 한계

for문으로 한 줄씩 처리하는 방식은 데이터가 많아질수록 느려집니다. 그리고 "클래스별 평균 면적", "이미지별 객체 수 분포", "특정 조건의 데이터만 골라 통계내기" 같은 작업을 지금 방식으로 하려면 코드가 급격히 복잡해집니다.

작업지금 방식Numpy · Pandas
수천 개 숫자의 평균반복문으로 누적arr.mean()
조건에 맞는 행만 추출반복문 + 조건문 + appenddf[df.conf >= 0.7]
클래스별 그룹 집계딕셔너리로 직접 구현df.groupby("class").mean()

다음 시간부터 배우는 Numpy는 숫자 계산을, Pandas는 표 형태 데이터를 다루는 데 특화된 도구입니다. 훨씬 짧고 빠른 코드로 같은 일을 할 수 있게 됩니다.

💡 오늘 배운 것은 헛수고가 아닙니다

Pandas 코드를 이해하려면 리스트·딕셔너리 구조를 알아야 하고, Pandas의 apply()에는 함수를 넘겨야 하며, 데이터가 이상할 때는 결국 예외처리로 방어해야 합니다. 지금 익힌 기초 위에서만 그 도구들을 제대로 쓸 수 있습니다.
