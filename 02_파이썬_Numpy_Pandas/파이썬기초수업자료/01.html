VSCode 설치와 개발환경 구성

VSCode(Visual Studio Code)는 코드를 작성하고 바로 실행 결과를 확인할 수 있는 편집기입니다. 메모장과 달리 코드에 오류가 있으면 빨간 밑줄로 알려주고, 자동완성을 지원하며, 터미널이 내장되어 있습니다.

1단계 · VSCode 설치

  1. code.visualstudio.com 접속 → Download for Windows 클릭
  2. 다운로드된 설치 파일 실행 → 기본값 그대로 다음(Next)을 눌러 진행
  3. 설치 옵션 중 "PATH에 추가(Add to PATH)" 체크박스는 반드시 체크된 상태로 진행
  4. 설치 완료 후 VSCode 실행

2단계 · 확장(Extension) 설치

왼쪽 사이드바에서 네모 4개 모양의 아이콘(확장)을 클릭하고 아래를 검색해 설치합니다.

  1. 바탕화면이나 문서 폴더에 python_study 같은 이름으로 새 폴더 생성

코드를 실행하는 세 가지 방법

파이썬 코드를 실행하는 방법은 하나가 아닙니다. 상황에 따라 편한 방법을 고르면 됩니다.

방법 1 · .py 파일로 저장해서 실행

가장 기본적이고 실무에서 가장 많이 쓰는 방법입니다. 탐색기에서 새 파일을 만들고 이름을 hello.py로 저장합니다. 확장자 .py가 "이 파일은 파이썬 코드"라는 표시입니다.

hello.py
# [목적] 화면에 문장을 출력하는 가장 기본적인 코드
print("안녕하세요, 파이썬!")

저장한 뒤 편집기 오른쪽 위의 ▶ 실행 버튼을 누르거나, 터미널에서 직접 실행합니다.

터미널
$ python hello.py
안녕하세요, 파이썬!

방법 2 · 인터랙티브 창에서 한 블록씩 실행

값을 바꿔가며 즉시 결과를 확인하고 싶을 때 유용합니다. 코드 위에 # %%를 적으면 그 아래가 하나의 "셀"이 되고, Run Cell 버튼이 나타납니다.

quick_test.py
# %%
width = 4848
height = 2704
print(width * height)

방법 3 · 노트북(.ipynb)에서 실행

여러 실험 결과를 순서대로 기록하며 진행할 때 사용합니다. 확장자가 .ipynb인 파일을 만들면 자동으로 노트북 형태로 열립니다. 이후 Numpy·Pandas 수업에서 데이터를 살펴볼 때 가장 많이 쓰게 될 방식이므로, 지금은 존재만 알아두면 됩니다.

변수와 자료형

변수는 값을 담아두는 이름표입니다. 상자에 이름표를 붙이고 값을 넣어둔다고 생각하면 됩니다. 나중에 이름표만 부르면 그 안의 값을 다시 꺼내 쓸 수 있습니다.

📌 대입은 "같다"가 아니라 "넣는다"

수학에서 x = 5는 "x와 5가 같다"는 뜻이지만, 파이썬에서는 "5라는 값을 x라는 이름표에 넣는다"는 뜻입니다. 그래서 count = count + 1 같은 코드가 성립합니다 — 오른쪽을 먼저 계산해서 그 결과를 왼쪽 이름표에 다시 넣는 것이죠.

파이썬의 기본 자료형 4가지

자료형이름의미예시
int정수소수점이 없는 수. 개수, 번호, 픽셀 좌표4848, 6, -3
float실수소수점이 있는 수. 신뢰도, 비율, 평균0.87, 3.14
str문자열따옴표로 감싼 글자. 파일명, 클래스 이름"나뭇잎류"
bool불리언참/거짓 두 가지 값만 가짐. 판정 결과True, False
⚠️ 변수 이름 규칙
  • 영문자·숫자·밑줄(_)만 사용, 숫자로 시작할 수 없음 (1st_image ✗ → image_1 ✓)
  • 대소문자 구분: width와 Width는 서로 다른 변수
  • 여러 단어는 밑줄로 연결하는 스네이크 케이스가 관례: class_id, is_defect
  • print, list, type 같은 파이썬 내장 이름은 변수명으로 쓰지 않기

기본 1변수 만들고 출력하기

d1_var_01.py
# [목적] 변수에 값을 넣고 print()로 확인하는 가장 기본적인 형태
# [설명] = 기호 왼쪽이 이름표, 오른쪽이 담을 값입니다.

변수를 만드는 순간 파이썬은 값의 종류를 스스로 판단합니다. C나 자바처럼 int count;라고 타입을 미리 선언할 필요가 없어서, 처음 배우는 사람에게 부담이 적습니다.

기본 2네 가지 자료형과 type() 확인

d1_var_02.py
# [목적] int, float, str, bool 네 가지 기본 자료형을 각각 확인한다
# [설명] type()은 괄호 안 값이 어떤 자료형인지 알려주는 확인용 도구입니다.

a = 100          # int  : 정수
b = 3.14         # float: 실수
c = "파이썬"      # str  : 문자열
d = True         # bool : 참/거짓

print(a, type(a))
print(b, type(b))
print(c, type(c))
print(d, type(d))
실행 결과
100 <class 'int'>
3.14 <class 'float'>
파이썬 <class 'str'>
True <class 'bool'>

출력에 보이는 <class 'int'>는 "이 값은 int라는 종류에 속한다"는 뜻입니다. 나중에 계산이 이상하게 나올 때 type()으로 찍어보면 원인을 빨리 찾을 수 있습니다.

기본 3변수 값 바꾸기와 누적하기

d1_var_03.py
# [목적] 변수는 언제든 새 값으로 덮어쓸 수 있다는 것을 확인한다
# [설명] count = count + 1 은 "현재 값에 1을 더해 다시 넣기"입니다.

count = 0
print("시작:", count)

count = count + 1
print("한 번 더한 뒤:", count)

count += 1          # count = count + 1 의 줄임 표현
count += 1
print("세 번 더한 뒤:", count)
실행 결과
시작: 0
한 번 더한 뒤: 1
세 번 더한 뒤: 3

+=는 실무 코드에서 거의 항상 쓰이는 축약형입니다. 개수를 세거나 합계를 구할 때 반복문 안에서 이 형태를 계속 보게 됩니다.

기본 4여러 변수를 한 번에 만들기

d1_var_04.py
# [목적] 한 줄에 여러 변수를 동시에 만드는 방법
# [설명] 콤마로 나란히 적으면 순서대로 짝지어 들어갑니다.

x, y = 120, 85
print("x =", x, "/ y =", y)

# 두 값을 서로 맞바꾸기 (임시 변수 없이)
x, y = y, x
print("맞바꾼 뒤 x =", x, "/ y =", y)

# 같은 값을 여러 변수에 한꺼번에
w = h = 0
print("w =", w, "/ h =", h)
실행 결과
x = 120 / y = 85
맞바꾼 뒤 x = 85 / y = 120
w = 0 / h = 0

좌표처럼 짝을 이루는 값을 다룰 때 자주 쓰는 표현입니다. 특히 x, y = y, x는 다른 언어라면 임시 변수가 필요한 작업을 한 줄로 끝내줍니다.

기본 5자료형 바꾸기 (형변환)

d1_var_05.py
# [목적] 문자열로 된 숫자를 계산 가능한 숫자로 바꾸는 방법
# [설명] int(), float(), str() 로 자료형을 서로 변환합니다.

text_number = "42"
print(text_number + text_number)      # 문자열끼리 더하면 이어붙이기

real_number = int(text_number)
print(real_number + real_number)      # 숫자끼리 더하면 덧셈

score = 0.876
print("신뢰도: " + str(score))         # 숫자를 문자열로 바꿔야 이어붙일 수 있음
실행 결과
4242
84
신뢰도: 0.876

"42" + "42"가 "4242"가 되는 것이 형변환이 필요한 대표적인 이유입니다. 파일에서 읽은 값은 항상 문자열이므로, 계산하려면 반드시 int()나 float()로 바꿔야 합니다.

실무 1이미지 한 장의 정보 관리하기

d1_var_a1.py
# [목적] 조각김치 이물검출 이미지 한 장의 메타 정보를 변수로 정리한다
# [설명] 실제 제공 데이터는 4848x2704 해상도의 JPG 이미지입니다.

file_name = "kimchi_0001.jpg"
width = 4848
height = 2704
channels = 3                      # RGB 3채널

total_pixels = width * height
print("파일명:", file_name)
print("해상도:", width, "x", height)

이미지를 다루기 전에 크기를 파악하는 것은 필수입니다. 4848×2704 이미지 한 장을 원본 그대로 메모리에 올리면 약 37MB를 차지하므로, 학습 시 왜 이미지를 640×640으로 줄이는지 이 계산으로 이해할 수 있습니다.

실무 2검출 결과 하나를 변수로 표현하기

d1_var_a2.py
# [목적] 객체검출 모델이 내놓는 결과 한 건을 변수들로 표현한다
# [설명] 클래스ID, bbox 좌표, 신뢰도가 검출 결과의 3요소입니다.

class_id = 1                      # 1 = 나뭇잎류
class_name = "나뭇잎류"
x, y = 120, 85                    # bbox 좌상단 좌표
box_width, box_height = 40, 30    # bbox 크기

# [목적] Confusion Matrix 값에서 Precision·Recall·F1을 직접 계산한다
# [설명] 최종 프로젝트 평가에서 직접 설명해야 하는 지표들입니다.

TP = 85     # True Positive : 이물인데 이물이라 맞춘 것
FP = 15     # False Positive: 정상인데 이물이라 잘못 잡은 것
FN = 10     # False Negative: 이물인데 놓친 것

precision = TP / (TP + FP)      # 이물이라 한 것 중 진짜 이물 비율
recall = TP / (TP + FN)         # 진짜 이물 중 찾아낸 비율
f1 = 2 * precision * recall / (precision + recall)

print("Precision:", round(precision, 3))
print("Recall   :", round(recall, 3))
print("F1 Score :", round(f1, 3))
print("목표(0.7) 달성?", f1 >= 0.7)

이미지 파일명, 라벨 정보, 로그 기록, 결과 리포트 — 실습에서 만나는 데이터의 상당 부분이 문자열입니다. 문자열을 자르고, 나누고, 바꾸고, 조립하는 능력이 이후 모든 데이터 처리의 기초가 됩니다.

인덱싱과 슬라이싱

문자열의 각 글자에는 0부터 시작하는 번호가 붙어 있습니다. 뒤에서부터는 -1부터 셉니다.

글자kimchi
앞에서012345
뒤에서-6-5-4-3-2-1

문자열[시작:끝]으로 구간을 잘라내며, 끝 번호는 포함되지 않습니다. "kimchi"[0:3]은 0,1,2번 글자인 "kim"입니다.

자주 쓰는 문자열 메서드

.join(리스트)리스트를 하나의 문자열로 합치기",".join(['a','b']) → 'a,b'

int(input(...))처럼 한 줄로 묶어 쓰는 것이 일반적입니다. 다만 사용자가 숫자가 아닌 값을 넣으면 오류가 나므로, Day 3에서 배울 예외처리와 함께 쓰는 것이 안전합니다.

# [목적] 공백으로 구분된 여러 값을 한 번에 받아 나눈다
# [설명] input() 후 split()으로 쪼개는 것이 정석입니다.

data = input("너비와 높이를 공백으로 구분해 입력: ")

width = int(parts[0])
height = int(parts[1])

print("면적:", width * height)

# 더 짧게 쓰는 방법
w, h = input("다시 입력: ").split()

w, h = ....split()은 나눠진 조각을 각 변수에 바로 배분하는 방법입니다. 다만 입력 개수가 안 맞으면 오류가 나므로 개수가 확실할 때만 사용합니다.

기본 5출력 형식 다듬어 표처럼 보이게 하기

# [목적] 문자열 정렬 기능으로 출력을 표 형태로 만든다

print(f"{'클래스':<12}{'개수':>6}{'비율':>10}")
print("-" * 28)
print(f"{'나뭇잎류':<12}{27:>6}{0.45:>10.1%}")
print(f"{'플라스틱류':<12}{15:>6}{0.25:>10.1%}")

# [목적] YOLO 정규화 좌표를 입력받아 픽셀 좌표로 변환해 보여준다
# [설명] 라벨이 제대로 찍혔는지 수동 확인할 때 쓰는 도구입니다.

img_w = int(input("이미지 너비(px): "))

px_w, px_h = w * img_w, h * img_h
x1 = cx * img_w - px_w / 2

x2 = x1 + px_w
y2 = y1 + px_h

print(f"우하단    : ({x2:.0f}, {y2:.0f})")
print(f"크기      : {px_w:.0f} x {px_h:.0f} px")
print(f"범위 정상 : {0 <= x1 and 0 <= y1 and x2 <= img_w and y2 <= img_h}")
