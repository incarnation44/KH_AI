사전 준비 확인하기

설치 전에 딱 두 가지만 확인하면 됩니다.

① Windows 버전 확인. WSL2는 Windows 11이거나, Windows 10이라면 버전 2004(빌드 19041) 이상이어야 합니다. Win + R 키를 누르고 winver를 입력한 뒤 Enter를 치면 현재 버전이 뜹니다.

② 가상화(Virtualization) 활성화 확인. WSL2는 내부적으로 가상 머신을 사용하기 때문에, PC의 가상화 기능이 켜져 있어야 합니다.

  • Ctrl + Shift + Esc로 작업 관리자를 엽니다.
  • 성능 탭 → CPU 항목을 클릭합니다.
  • 오른쪽 아래 가상화 항목이 "사용"으로 표시되면 통과입니다.
⚠ 가상화가 "사용 안 함"으로 나온다면 메인보드 제조사마다 다르지만, PC를 재시작하면서 Del, F2, F10 중 하나를 눌러 BIOS(UEFI) 화면에 들어간 뒤, Intel VT-x 또는 AMD-V(SVM Mode) 항목을 찾아 Enabled로 바꾸고 저장(F10) 후 재시작하세요.
01

WSL 설치하기

여기서부터는 전부 Windows PowerShell 창에서 진행합니다.

PowerShell을 관리자 권한으로 실행합니다. 시작 메뉴를 열고 "PowerShell"을 검색한 뒤, 검색 결과를 마우스 오른쪽 버튼으로 클릭 → "관리자 권한으로 실행"을 선택하세요. 관리자 권한이 아니면 설치 중간에 오류가 날 수 있습니다.

PowerShell (관리자)
설치 가능한 배포판 목록 확인
PS> wsl --list --online
# 목록에 Ubuntu-24.04 가 있는지 확인합니다

목록에 Ubuntu-24.04가 보인다면 바로 설치를 진행합니다.

PowerShell (관리자)
WSL + Ubuntu 24.04 한 번에 설치
PS> wsl --install -d Ubuntu-24.04

이 명령 하나로 WSL 기능 활성화 → 가상 머신 플랫폼 설치 → 리눅스 커널 설치 → Ubuntu 24.04 다운로드까지 자동으로 진행됩니다. 인터넷 속도에 따라 몇 분 정도 걸립니다.

💡 이미 WSL을 예전에 설치한 적이 있다면 먼저 wsl --update 명령으로 WSL 자체를 최신 버전으로 업데이트한 다음, 위의 설치 명령을 다시 실행하세요.

설치가 끝나면 "컴퓨터를 다시 시작해야 합니다"라는 안내가 나올 수 있습니다. 이 경우 PC를 재부팅하세요.

재시작 후에도 자동으로 열리지 않는다면, 시작 메뉴에서 "Ubuntu 24.04"를 검색해서 직접 실행하세요.

잠시 후 사용자 이름을 입력하라는 문구가 나타납니다. 다음 단계에서 계속 이어집니다.

03

사용자 계정 · 비밀번호 설정하기

Ubuntu 안에서 쓸 나만의 리눅스 계정을 처음 만드는 단계입니다.
Ubuntu 24.04 터미널
계정 생성 프롬프트
Enter new UNIX username: hyunmin
New password: 
Retype new password: 
passwd: password updated successfully
installation successful!
  • Enter new UNIX username — Windows 계정 이름과 달라도 됩니다. 영문 소문자로, 띄어쓰기 없이 입력하세요. (예: hyunmin)
  • New password — 원하는 비밀번호를 입력합니다.
  • Retype new password — 확인을 위해 같은 비밀번호를 한 번 더 입력합니다.
💡 타이핑을 하는데 화면에 아무것도 안 보여요 정상입니다. 리눅스 터미널은 비밀번호를 입력할 때 글자는 물론 별표(*)조차 표시하지 않습니다. 옆에서 누가 봐도 몇 글자인지 알 수 없게 하기 위한 보안 습관입니다. 잘 입력되고 있으니 그대로 타이핑하고 Enter를 누르면 됩니다.

installation successful! 메시지가 뜨고 사용자이름@PC이름:~$ 형태의 프롬프트가 보이면 설치가 완전히 끝난 것입니다.

제대로 설치됐는지 확인하기

Windows 쪽과 Ubuntu 쪽, 양쪽에서 한 번씩 확인해봅니다.
PowerShell
설치된 배포판 · 버전 확인
PS> wsl --list --verbose

  NAME            STATE           VERSION
* Ubuntu-24.04    Running         2

VERSION이 2로 표시되어야 합니다. WSL1이 아닌 WSL2로 설치된 것을 확인하는 항목입니다.

Ubuntu 24.04 터미널
Ubuntu 버전 확인

Description:    Ubuntu 24.04.1 LTS

Codename:       noble
05

비밀번호 변경하기 (기억하고 있을 때)

현재 비밀번호를 알고 있는 상태에서 새 비밀번호로 바꾸는 방법입니다.
Ubuntu 24.04 터미널
passwd 명령으로 변경
$ passwd
Changing password for hyunmin.
Current password: 
New password: 
Retype new password: 
passwd: password updated successfully

Current password에는 지금 쓰고 있는 비밀번호를, 그 아래 두 줄에는 새로 쓸 비밀번호를 입력합니다. 여기서도 화면에는 아무것도 표시되지 않는 것이 정상입니다.

06

비밀번호를 잊어버렸을 때 복구하기

가장 많이 헤매는 부분입니다. 침착하게 아래 순서대로 따라 하면 됩니다.

핵심 원리는 이렇습니다. Windows에 관리자로 로그인되어 있다면, 그 자체로 WSL 안의 root(관리자) 계정에 비밀번호 없이 들어갈 수 있는 권한을 이미 가지고 있습니다. root로 한 번 들어가서 잊어버린 계정의 비밀번호를 강제로 새로 설정해주면 됩니다.

PowerShell
① 실행 중인 WSL 완전히 종료
PS> wsl --shutdown
PowerShell
② root 계정으로 Ubuntu 진입
PS> wsl -d Ubuntu-24.04 -u root
# 비밀번호를 묻지 않고 바로 root@... 프롬프트로 들어갑니다
Ubuntu 24.04 터미널 (root)
③ 비밀번호를 잊은 계정의 새 비밀번호 설정
root# passwd hyunmin
New password: 
Retype new password: 
passwd: password updated successfully

hyunmin 자리에는 실제 본인의 사용자 이름을 넣습니다. root는 상대방의 기존 비밀번호를 몰라도 새 비밀번호를 강제로 지정할 수 있습니다.

Ubuntu 24.04 터미널 (root)
④ root 세션 종료
root# exit

이제 시작 메뉴에서 Ubuntu 24.04 앱을 평소처럼 실행하면, 방금 설정한 새 비밀번호로 정상적으로 로그인됩니다.

⚠ 알아두어야 할 점 이 복구 방법이 통하는 이유는 WSL의 리눅스 계정 비밀번호가 sudo 명령을 쓸 때 확인용으로만 쓰이는 로컬 잠금장치이기 때문입니다. Windows 관리자 계정 자체를 보호하는 것은 아니므로, 실제 중요한 데이터 보안은 Windows 로그인 비밀번호와 디스크 암호화(BitLocker) 쪽에서 관리해야 합니다.

08

자주 발생하는 문제 해결

설치 중 막히는 대부분의 경우는 아래 세 가지 중 하나입니다.

"이 컴퓨터에서는 가상화 지원이 사용하도록 설정되어 있지 않습니다" 라는 오류가 뜬다면, 위의 0단계로 돌아가 BIOS에서 가상화(VT-x / AMD-V)를 켜주세요.

"WSL 2 requires an update to its kernel component" 오류가 뜬다면, 마이크로소프트에서 배포하는 커널 업데이트 패키지를 설치해야 합니다.

PowerShell
기본 버전을 WSL2로 지정
PS> wsl --set-default-version 2

wsl --install 명령 자체가 인식되지 않거나 실패한다면, Windows 기능을 하나씩 수동으로 켜는 방법이 있습니다.

PowerShell (관리자)
Windows 기능 수동 활성화
PS> dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
PS> dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

두 명령을 실행한 뒤 PC를 재시작하고, wsl --set-default-version 2를 실행한 다음 Microsoft Store에서 "Ubuntu 24.04 LTS"를 검색해 직접 설치하면 됩니다.

💡 그래도 안 될 때 Windows 업데이트가 오래된 경우가 많습니다. 설정 → Windows Update에서 최신 업데이트를 모두 설치한 뒤 재부팅하고 다시 시도해보세요.
