PART 1. 이론

1교시 · 시스템 패키지 관리

1.1 apt

sudo apt update                    # 패키지 목록 갱신 (설치 전 항상)
sudo apt upgrade                   # 설치된 패키지 업그레이드
sudo apt install 패키지명
sudo apt install -y build-essential git curl wget htop tree
sudo apt remove 패키지명
sudo apt autoremove                # 불필요 의존성 정리
apt list --installed | grep python
apt show 패키지명

1.2 이 과정에서 필요한 시스템 패키지

sudo apt install -y \
  build-essential \        # 컴파일러 (일부 파이썬 패키지 빌드에 필요)
  git curl wget \
  vim nano tmux htop tree \
  python3-dev \
  libgl1 libglib2.0-0 \    # OpenCV 실행에 필수 ★
  ffmpeg                   # 비디오 처리 (교과 3·10·15)

libgl1 을 모르면 반드시 겪는 오류 ImportError: libGL.so.1: cannot open shared object file pip install opencv-python 은 됐는데 import cv2 에서 죽습니다. 교과 3 첫날 30명 중 절반이 만나는 오류입니다. 시스템 라이브러리와 파이썬 패키지는 별개라는 것이 핵심 개념입니다.

1.3 파이썬 패키지 관리의 3층 구조

┌────────────────────────────────────────┐
│ ③ 프로젝트 패키지 (torch, opencv, ...)    │ ← pip / conda
├────────────────────────────────────────┤
│ ② 파이썬 인터프리터 (3.10, 3.11 ...)      │ ← conda / pyenv
├────────────────────────────────────────┤
│ ① 시스템 라이브러리 (libGL, ffmpeg ...)    │ ← apt
└────────────────────────────────────────┘

에러를 만났을 때 어느 층의 문제인지 판단하는 것이 디버깅의 시작입니다.

2교시 · 가상환경 — 왜 필요한가

2.1 격리하지 않으면 생기는 일

시나리오 - 교과 5 딥러닝: PyTorch 2.1 + CUDA 11.8 - 교과 11 생성모델: diffusers가 PyTorch 2.4 요구 - 교과 13 Raspberry Pi: TensorFlow Lite (경량 버전) - 교과 14 Jetson: TensorRT 호환 특정 버전

이걸 전부 시스템 파이썬 하나에 설치하면? → pip install 할 때마다 이전 패키지가 덮어씌워지고, 어제 되던 코드가 오늘 안 됩니다.

2.2 격리 도구 비교

venv conda Docker
파이썬 버전 변경 불가 가능 가능
비파이썬 의존성 (CUDA, ffmpeg) 불가 가능 가능
설치 크기 작음 큼 매우 큼
학습 난이도 쉬움 보통 어려움
본 과정 보조 주력 교과 13/14 참고

안내서에 「Anaconda 3(Python 3.10 이상)」이 명시되어 있으므로 conda를 주력으로 사용합니다.

2.3 conda 명령 체계

# 환경 관리
conda create -n 환경명 python=3.10
conda create -n 환경명 python=3.10 numpy pandas -y
conda env list                       # 또는 conda info --envs
conda activate 환경명
conda deactivate
conda env remove -n 환경명
conda create -n 새환경 --clone 기존환경

# 패키지 관리
conda install 패키지명
conda install -c conda-forge 패키지명    # 채널 지정
conda list
conda list | grep torch
conda update 패키지명
conda remove 패키지명

# 환경 내보내기 / 재현 ★★
conda env export > environment.yml
conda env export --no-builds > environment.yml     # 크로스 플랫폼 권장
conda env export --from-history > environment.yml  # 명시 설치만 (가장 깔끔)
conda env create -f environment.yml
conda env update -f environment.yml --prune

# 정리
conda clean --all                    # 캐시 삭제 (디스크 확보)

2.4 conda와 pip 혼용 규칙 ★

황금 규칙 1. conda를 먼저, pip를 나중에 2. pip로 설치한 뒤 conda로 다시 설치하지 않는다 3. 한 환경에서 순서를 지키고, 섞였으면 환경을 지우고 다시 만든다 4. sudo pip install 절대 금지

conda activate vision-ai
# 1) conda 먼저
conda install numpy pandas matplotlib -y
# 2) conda에 없는 것만 pip
pip install ultralytics

왜? conda와 pip는 서로의 설치 기록을 모릅니다. 같은 패키지를 각각 설치하면 파일이 충돌해 ImportError가 나고, 원인 추적이 매우 어렵습니다.

2.5 재현성 — 평가와 직결

안내서 평가항목 「코드 품질 — 재사용성」과 「프로젝트 완성도」에 직결됩니다.

최종 프로젝트 제출물에 반드시 포함해야 할 것

environment.yml       # conda 환경 정의
requirements.txt      # pip 목록 (보조)
README.md             # 설치·실행 절차

심사자가 conda env create -f environment.yml 한 줄로 여러분의 환경을 재현하지 못하면, 그 프로젝트는 "동작하지 않는 프로젝트"로 평가됩니다.

3교시 · 대용량 데이터셋 디렉토리 설계

3.1 이 과정에서 다룰 데이터 규모

교과 데이터 규모
교과 8 조각김치 + 이물 (4848×2704 JPG) 약 1,000장 + 라벨 TXT
교과 14 컨베이어 촬영 최소 500장 · 분류 5종 이상
교과 15 모션캡처 Keypoint 동작 10종 이상 × 다수 Take
교과 11 합성데이터 생성 결과 수천 장

4848×2704 JPG 1장이 약 3~5MB → 1,000장이면 3~5GB. 학생 PC SSD는 512GB. 여기에 증강본·분할본·체크포인트가 쌓이면 금방 찹니다.

3.2 설계 5원칙

원칙 1. 원본 불변 (Immutable Raw)

raw/           읽기 전용. 절대 수정·삭제 안 함
processed/     전처리 결과 (언제든 raw에서 재생성 가능)

raw를 덮어쓰면 그 데이터셋은 재현 불가능해집니다. 평가항목 「데이터 품질」 감점 1순위.

원칙 2. 분할은 링크로 (Space-efficient Split)

images/train/img_001.jpg -> ../../raw/img_001.jpg

2일차에서 배운 심볼릭 링크. 용량 2배 증가를 막습니다.

원칙 3. 메타데이터 동봉 (Self-describing)

meta/
├── classes.txt          클래스 정의
├── data.yaml            학습 프레임워크 설정
├── DATASET.md           출처·수집조건·라이선스·주의사항
├── split_seed.txt       분할 재현용 시드
└── checksums.md5        무결성 검증

6개월 뒤 이 데이터를 다시 볼 때, 문서가 없으면 아무도 못 씁니다.

원칙 4. 명명 규칙 통일 (Naming Convention)

{prefix}_{date}_{device}_{sequence}.{ext}

conv_20260826_cam01_000123.jpg      # 교과 14 컨베이어
motion_20260901_take03_frame0450.jpg  # 교과 15 모션

규칙: - 소문자 + 언더스코어만 (공백·한글·대문자 금지) - 순번은 0 패딩 (001 not 1) → 정렬이 맞음 - 이미지와 라벨은 확장자만 다르고 이름 동일

원칙 5. 버전 관리 분리 (VCS Separation)

대상 Git 이유
코드, 설정, meta 문서 ✅ 포함 작고 변경 추적 필요
이미지, 동영상 ❌ 제외 용량, ㈜비솔 데이터는 업로드 금지
모델 가중치 .pt ❌ 제외 (LFS 검토) 수백 MB
로그, 캐시 ❌ 제외 재생성 가능

⚠️ 안내서 6.2절·7장 규정: ㈜비솔 제공 데이터는 원내 폐쇄망 전용이며 외부 클라우드 및 GitHub 업로드 금지, 개인별 보안서약서 대상입니다. .gitignore 설계가 규정 준수 수단입니다(7일차에 pre-commit 훅으로 강제).

3.3 표준 레이아웃 (본 과정 공식)

dataset/<name>/
├── raw/                          원본 (444/555 권한)
│   ├── images/
│   └── labels/
├── processed/                    전처리 결과
├── images/                       학습용 (심볼릭 링크)
│   ├── train/  val/  test/
├── labels/
│   ├── train/  val/  test/
├── meta/
│   ├── classes.txt
│   ├── data.yaml
│   ├── DATASET.md
│   ├── split_seed.txt
│   ├── class_distribution.txt
│   └── qc_report.txt
├── backup/
└── .gitignore

교과 8에서 YOLO 학습을 시작할 때 첫 번째로 만들 파일입니다.

3.5 분할 원칙

항목 규칙 근거
비율 7 : 1.5 : 1.5 안내서 교과 14 명시
방식 무작위 + 고정 시드 재현성
층화(stratify) 클래스 비율 유지 권장 소수 클래스 보호
누수 방지 같은 원본에서 나온 증강본은 같은 split에 데이터 누수 방지 ★

데이터 누수(Data Leakage): 같은 이미지를 회전시킨 증강본이 train에, 원본이 test에 들어가면 test 성능이 과대평가됩니다. mAP 0.9가 나왔는데 현장에서 0.4인 전형적 원인입니다.

실습 5-1 · Anaconda 설치와 환경 구성

Step 1. 설치 확인 / 설치

conda --version           # 이미 설치되어 있으면 버전 출력

미설치 시 (강사가 배포한 오프라인 인스톨러 사용 권장):

cd /tmp
# 강사 배포 경로 또는 다운로드
bash Anaconda3-2024.10-1-Linux-x86_64.sh
# 라이선스 → yes / 경로 → 기본(~/anaconda3) / conda init → yes

Step 2. 초기 설정

conda config --set auto_activate_base false    # base 자동 활성화 끄기 ★
conda config --add channels conda-forge
conda config --show channels
conda config --set channel_priority flexible

exec bash                  # 셸 재시작

auto_activate_base false 를 권장하는 이유: 프롬프트에 항상 (base)가 붙으면 훈련생이 어느 환경에 있는지 인지하지 못합니다. 명시적으로 activate 하는 습관이 중요합니다.

which python              # ~/anaconda3/envs/vision-ai/bin/python
python --version          # Python 3.10.x
which pip

Step 4. 격리 체험 실험 ★

Step 6. environment.yml 내보내기 ★

wc -l env/*.yml

head -20 env/environment.yml

Step 7. 재현 테스트 (짝 실습) ★★

2인 1조로 진행합니다.

# B: 전달받은 파일로 환경 재현

conda list | wc -l

conda deactivate
conda env remove -n reproduce-test -y

#!/bin/bash
#===============================================================
# 파일명 : split_dataset.sh
# 목적   : YOLO 데이터셋을 train/val/test 로 분할 (심볼릭 링크)
# 사용법 : ./split_dataset.sh <dataset_dir> [옵션]
# 작성일 : 2026-08-30
#===============================================================
set -uo pipefail

readonly SCRIPT_NAME=$(basename "$0")
TRAIN_R=70; VAL_R=15; TEST_R=15
SEED=42
MODE="link"
CLEAN=0

usage () {
    cat << EOF
사용법: $SCRIPT_NAME <dataset_dir> [옵션]

옵션:
  --ratio T:V:S   분할 비율 (기본 70:15:15)
  --seed N        난수 시드 (기본 42)
  --copy          링크 대신 복사
  --clean         기존 분할 삭제 후 재분할
  -h, --help      도움말
EOF
    exit 2
}

log ()  { echo "[$(date '+%H:%M:%S')] $*"; }
err ()  { echo "[ERROR] $*" >&2; exit 1; }

parse_args () {
    [ $# -eq 0 ] && usage
    DS="$1"; shift
    while [ $# -gt 0 ]; do
        case "$1" in
            --ratio) shift
                TRAIN_R=$(echo "$1" | cut -d: -f1)
                VAL_R=$(echo   "$1" | cut -d: -f2)
                TEST_R=$(echo  "$1" | cut -d: -f3) ;;
            --seed)  shift; SEED="$1" ;;
            --copy)  MODE="copy" ;;
            --clean) CLEAN=1 ;;
            -h|--help) usage ;;
            *) err "알 수 없는 옵션: $1" ;;
        esac
        shift
    done
}

validate () {
    [ -d "$DS" ] || err "경로 없음: $DS"
    [ -d "$DS/raw/images" ] || err "raw/images 없음"
    [ -d "$DS/raw/labels" ] || err "raw/labels 없음"
    local sum=$((TRAIN_R + VAL_R + TEST_R))
    [ "$sum" -eq 100 ] || err "비율 합이 100이 아님: $sum"
}

clean_splits () {
    log "기존 분할 삭제"
    rm -rf "$DS"/images/{train,val,test} "$DS"/labels/{train,val,test}
}

build_list () {
    # 라벨이 존재하는 이미지만 대상으로
    : > /tmp/_valid.$$
    for img in "$DS"/raw/images/*.jpg; do
        [ -e "$img" ] || continue
        local base
        base=$(basename "$img" .jpg)
        if [ -s "$DS/raw/labels/$base.txt" ]; then
            echo "$base" >> /tmp/_valid.$$
        fi
    done
    TOTAL=$(wc -l < /tmp/_valid.$$)
    log "유효 샘플(이미지+라벨 쌍): $TOTAL 개"
    [ "$TOTAL" -gt 0 ] || err "유효 샘플 없음"

    # 고정 시드 셔플 (재현 가능)
    awk -v seed="$SEED" 'BEGIN{srand(seed)} {print rand()"\t"$0}' /tmp/_valid.$$ \
      | sort -k1,1n | cut -f2 > /tmp/_shuf.$$
}

do_split () {
    N_TRAIN=$(( TOTAL * TRAIN_R / 100 ))
    N_VAL=$((   TOTAL * VAL_R   / 100 ))
    N_TEST=$((  TOTAL - N_TRAIN - N_VAL ))
    log "분할: train=$N_TRAIN val=$N_VAL test=$N_TEST"

    mkdir -p "$DS"/images/{train,val,test} "$DS"/labels/{train,val,test}

    head -n "$N_TRAIN"                            /tmp/_shuf.$$ > /tmp/_train.$$
    sed -n "$((N_TRAIN+1)),$((N_TRAIN+N_VAL))p"   /tmp/_shuf.$$ > /tmp/_val.$$
    sed -n "$((N_TRAIN+N_VAL+1)),\$p"             /tmp/_shuf.$$ > /tmp/_test.$$

    for split in train val test; do
        local list="/tmp/_${split}.$$"
        while read -r base; do
            local src_i="$DS/raw/images/$base.jpg"
            local src_l="$DS/raw/labels/$base.txt"
            if [ "$MODE" = "link" ]; then
                ln -sf "$(readlink -f "$src_i")" "$DS/images/$split/$base.jpg"
                ln -sf "$(readlink -f "$src_l")" "$DS/labels/$split/$base.txt"
            else
                cp "$src_i" "$DS/images/$split/"
                cp "$src_l" "$DS/labels/$split/"
            fi
        done < "$list"
    done
}

record_seed () {
    cat > "$DS/meta/split_seed.txt" << EOF
seed=$SEED
ratio=${TRAIN_R}:${VAL_R}:${TEST_R}
mode=$MODE
total=$TOTAL
train=$N_TRAIN
val=$N_VAL
test=$N_TEST
generated=$(date '+%F %T')
command=$SCRIPT_NAME $DS --ratio ${TRAIN_R}:${VAL_R}:${TEST_R} --seed $SEED
EOF
}

report () {
    echo ""
    echo "=============================================="
    printf "  %-8s %8s %8s\n" "SPLIT" "IMAGES" "LABELS"
    for s in train val test; do
        printf "  %-8s %8d %8d\n" "$s" \
            "$(ls "$DS/images/$s" 2>/dev/null | wc -l)" \
            "$(ls "$DS/labels/$s" 2>/dev/null | wc -l)"
    done
    echo "  ----------------------------------------"
    echo "  깨진 링크: $(find "$DS/images" "$DS/labels" -xtype l 2>/dev/null | wc -l)"
    echo "  시드 기록: $DS/meta/split_seed.txt"
    echo "=============================================="

    echo ""
    echo "  [split별 클래스 분포]"
    for s in train val test; do
        echo -n "  $s: "
        cat "$DS/labels/$s"/*.txt 2>/dev/null \
          | cut -d' ' -f1 | sort | uniq -c \
          | awk '{printf "c%s=%s ", $2, $1}'
        echo ""
    done
}

main () {
    parse_args "$@"
    validate
    [ "$CLEAN" -eq 1 ] && clean_splits
    build_list
    do_split
    record_seed
    report
    rm -f /tmp/_valid.$$ /tmp/_shuf.$$ /tmp/_train.$$ /tmp/_val.$$ /tmp/_test.$$
}

main "$@"
