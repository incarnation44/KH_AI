1. 교과 포지셔닝

1.1 이 교과가 과정에서 맡는 역할

안내서 「교과 1 · 리눅스」의 어디로 이어지는가 항목은 다음과 같이 규정되어 있습니다.

이후 전 교과의 개발환경 기반. Git/GitHub는 교과 7 이후 모든 프로젝트의 산출물 제출·평가 경로(코드 품질 KPI 측정도구)로 그대로 쓰임

즉 이 교과는 "리눅스 명령어를 배우는 시간"이 아니라, 앞으로 6.8개월간 훈련생이 사용할 작업 환경 그 자체를 세팅하고 규칙을 몸에 붙이는 시간입니다. 따라서 모든 실습 소재를 이후 교과에서 실제로 다룰 대상(조각김치 이물검출 이미지·YOLO 라벨 TXT·모션캡처 Keypoint JSON/CSV)으로 통일합니다.

5. 실습 데이터 준비 계획

5.1 문제 상황

㈜비솔 제공 조각김치·이물 이미지(약 1,000장 + TXT 라벨)는 9월 중순 제공 예정이며, 원내 폐쇄망 전용입니다. 교과 1은 과정 최초 교과이므로 실데이터 없이 시작할 가능성이 매우 높습니다.

5.2 대응 — 동형(同形) 더미 데이터셋 생성

실데이터와 디렉토리 구조·파일명 규칙·라벨 포맷이 완전히 동일한 더미 데이터셋을 1일차에 훈련생이 직접 생성합니다.

  • 이미지: 저용량 JPG 1,000장 (파일명 규칙만 실데이터와 동일)
  • 라벨: YOLO 포맷 TXT — class_id x_center y_center width height (전부 0~1 정규화 비율값)
  • 클래스 6종: 안내서 교과 8 이물 분류 6종과 동일하게 부여 1 나뭇잎류 / 2 플라스틱·돌·금속 / 3 나뭇가지류 / 4 고무장갑(미사용) / 5 병해·갈변 / 6 파·고추
  • 의도적 오류 주입: 라벨 없는 이미지, 이미지 없는 라벨, 좌표 범위 초과, 빈 파일, 공백 포함 파일명 → 3·4일차 검증 실습의 재료

실데이터 수령 후에는 동일 스크립트를 그대로 실행해 실데이터로 재검증합니다. 구조가 같으므로 교과 7·8 진입 시 추가 학습 없이 전환됩니다.

6.1 Ubuntu 제공 방식 — 3가지 안 비교

학생 PC가 Windows 11 · Ubuntu 22.04 병기이므로 운영 방식을 사전에 확정해야 합니다.

안 장점 단점 판단
A. 듀얼부팅 성능 100%, 실제 리눅스 경험 부팅 전환 번거로움, 파티션 사고 위험 비권장
B. WSL2 (Ubuntu 22.04) 설치 간편, Windows/VS Code 연동 우수, 스냅샷 백업 용이 systemd·GUI 일부 제약 권장(주 환경)
C. VirtualBox VM 완전 격리, 스냅샷 RAM 16GB에서 성능 부담 보조

권장안: B(WSL2)를 주 환경으로 하고, 7일차 SSH/원격 실습에서만 교실 내 리눅스 서버 또는 AWS 인스턴스에 접속. 단, 안내서상 학생 PC는 GPU가 없으므로 교과 5 이후 학습은 클라우드를 쓰게 됩니다. 교과 1에서 SSH·rsync·tmux를 반드시 익혀야 하는 이유가 여기 있습니다. ※ WSL2 채택 여부는 KH 학사 운영 담당과 사전 협의 필요 항목입니다(0교시 전 확정).

7.3 일일 체크리스트 예시 (1일차)

□ pwd / ls -al 출력을 읽고 각 컬럼의 의미를 설명할 수 있다
□ mkdir -p 로 3단계 이상 중첩 디렉토리를 한 번에 만든다
□ 절대경로와 상대경로로 같은 파일에 각각 접근한다
□ cp -r / mv / rm -r 를 구분해 사용한다
□ find 로 확장자 기준 파일 개수를 센다
□ 데이터셋 표준 폴더 구조를 명령어만으로 재현한다

9. 강사 운영 유의사항

  1. 비전공자 이탈 방지 — 1~2일차는 "왜 이걸 하는가"를 항상 Vision AI 맥락으로 연결합니다. 예: find를 가르칠 때 "라벨이 누락된 이미지 200장을 어떻게 찾을 것인가"에서 출발.
  2. 타이핑 강제 — 명령어 복사/붙여넣기를 1~3일차에는 금지하고 직접 타이핑하게 합니다. 4일차 이후 스크립트 작성부터 허용.
  3. 에러를 교재로 — 의도적 오류 데이터가 주입되어 있으므로, 에러 메시지를 읽고 원인을 말로 설명하는 훈련을 매 실습 포함.
  4. 커밋 시간 고정 — 매일 마지막 10분. 이 기록이 이후 교과 14·15 평가의 근거 자료가 됩니다.
  5. 보안 규정 반복 고지 — 안내서 6.2절·7장에 따라 ㈜비솔 제공 데이터는 원내 폐쇄망 전용이며 GitHub 업로드 금지입니다. 7일차 pre-commit 훅 실습은 이 규정을 기술적으로 강제하는 장치로 위치시킵니다.
  6. 교과 13 예고 — Raspberry Pi 실습(교과 13)이 리눅스 기반이므로, 3일차 Vim·4일차 SSH/tmux 실습 시 "이 화면이 라즈베리파이에서 그대로 반복된다"고 명시합니다.
