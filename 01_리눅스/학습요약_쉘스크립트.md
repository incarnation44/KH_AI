# 쉘 스크립트(Shell Script) 기초 학습 요약

## 1. 쉘 스크립트란?
* 터미널에 매번 명령어를 하나씩 입력하는 대신, 파일에 명령어들을 순서대로 작성해 두고 한 번에 일괄 실행하도록 만드는 '자동화 작업 지시서'입니다.

## 2. 권한 부여 및 실행 방법
* **실행 권한 부여**: chmod +x 파일명.sh
  * 리눅스의 보안 정책상 일반 문서는 프로그램처럼 바로 실행할 수 없으므로, +x (execute) 권한을 부여해 '실행 가능한 프로그램'으로 만들어 주어야 합니다.
* **스크립트 실행**: ./파일명.sh (현재 폴더에 있는 스크립트 파일 실행)

## 3. 인자 (Argument) 처리
* 스크립트 실행 시 외부에서 프로그램 안으로 던져주는 입력값(재료)을 의미합니다.
* 예시: ./hello.sh 홍길동 -> '홍길동'이 첫 번째 인자가 됩니다.
* **주요 내부 변수**:
  * $1,  ...: 각각 1번째 인자, 2번째 인자를 뜻합니다. (위 예시에서는 $1이 '홍길동'이 됨)
  * $#: 외부에서 던져준 인자의 총 개수를 뜻합니다. (위 예시에서는 1개)
  * ${1:-기본값}: 1번째 인자가 비어있을 경우 대신 사용할 기본값을 지정하는 문법입니다.

## 4. 디버깅(추적) 모드
* **실행 코드**: ash -x ./파일명.sh
* 컴퓨터가 스크립트 내부의 코드를 해석하고, 변수를 어떤 값으로 치환했는지 그 계산 과정을 화면에 투명하게 표시해 줍니다. 
* 기호 해석:
  * + : 실행을 준비 중인 코드 (컴퓨터의 해석 결과)
  * ++ : 문장 내에서 우선적으로 따로 계산된 보조 명령어 (예: $(date) 등)
  * 기호 없음 : 최종적으로 실제 화면에 출력된 행동 결과
