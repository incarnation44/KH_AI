명령어 연습 부록 — grep · sed · awk · vim 각 20제 + nano

쉬운 예제 10개 → 어려운 예제 10개 순서로, 명령어 하나하나가 "왜 이렇게 동작하는지" 손으로 확인합니다

이 문서의 목표: D3에서 배운 grep·sed·awk·vim이 "낯선 명령어"에서 "손에 익은 도구"가 되도록, 아주 쉬운 예제부터 실무에 가까운 예제까지 단계적으로 반복 연습합니다.

이 문서를 보는 법

  • 각 명령어마다 쉬움 10개 → 어려움 10개 순서로 배치되어 있습니다. 쉬움부터 순서대로 직접 타이핑해 보세요 (복사·붙여넣기보다 손으로 치는 것이 훨씬 오래 기억에 남습니다).
  • 모든 예제 코드블록은 $로 시작하는 줄이 "내가 입력하는 명령"이고, 그 아래 줄이 예상 결과(실제 화면에 뜨는 내용)입니다.
  • 각 예제 아래 의미 한두 줄이 "이 명령이 왜 이렇게 동작하는지"를 설명합니다. 결과가 예상과 다르게 나오면 이 설명을 다시 읽어보세요.
  • 중간에 막히면 언제든 D3 본문(03.html)의 해당 절로 돌아가 개념을 다시 확인하세요.

실습 준비 — 예제 파일 만들기

아래 명령을 한 번만 실행해서 연습용 폴더와 파일 3개를 만들어 둡니다. 이 문서의 모든 예제는 이 파일들을 기준으로 합니다.

mkdir -p ~/kdt-linux/cmd-practice && cd ~/kdt-linux/cmd-practice

# 파일 1. fruits.txt — 콤마(,)로 구분된 표 형태 데이터 (과일, 수량, 가격)
cat > fruits.txt << 'EOF'
apple,5,1200
banana,10,800
cherry,3,5000
date,0,3000
elderberry,7,4500
fig,2,2200
grape,15,900
honeydew,1,3500
kiwi,8,600
lemon,20,300
EOF

# 파일 2. server.log — 공백으로 구분된 서버 로그 (날짜 시간 레벨 메시지)
cat > server.log << 'EOF'
2026-08-20 09:01:12 INFO Server-started
2026-08-20 09:03:45 INFO User-login:kdt01
2026-08-20 09:15:30 WARNING Disk-usage-80%
2026-08-20 09:20:11 ERROR Connection-timeout
2026-08-20 09:20:15 INFO Retrying-connection
2026-08-20 09:20:20 INFO Connection-restored
2026-08-20 10:01:00 ERROR Out-of-memory
2026-08-20 10:01:05 INFO Process-restarted
2026-08-20 10:30:44 INFO User-logout:kdt01
2026-08-20 11:00:00 WARNING Disk-usage-95%
EOF

# 파일 3. sample.txt — vim 연습용 (과일 이름 5줄)
cat > sample.txt << 'EOF'
apple
banana
cherry
date
elderberry
EOF

ls -l

예상 결과: fruits.txt, server.log, sample.txt 3개 파일이 만들어집니다. 이후 모든 예제는 cd ~/kdt-linux/cmd-practice 상태에서 실행한다고 가정합니다.

1. grep — 원하는 줄 찾기

grep은 파일 안에서 내가 찾는 단어나 패턴이 들어있는 줄만 골라서 보여주는 명령어입니다. "긴 로그 파일에서 에러만 보고 싶다"가 grep이 존재하는 이유입니다.

grep · 쉬움 10제

  1. $ grep "apple" fruits.txt
apple,5,1200

    의미: "apple"이라는 글자가 들어있는 줄만 찾아서 보여줍니다. grep의 가장 기본 형태 — grep 찾을말 파일명.

  2. $ grep -i "APPLE" fruits.txt
apple,5,1200

    의미: 파일에는 소문자 "apple"만 있지만 대문자 "APPLE"로 검색해도 찾아냅니다. -i는 대소문자를 구분하지 않겠다는 옵션입니다.

  3. $ grep -c "ERROR" server.log
2

    의미: 매칭된 줄의 내용이 아니라 개수만 셉니다. "에러가 몇 번 발생했지?" 같은 질문에 바로 답하는 옵션입니다.

  4. $ grep -n "WARNING" server.log
3:2026-08-20 09:15:30 WARNING Disk-usage-80%
10:2026-08-20 11:00:00 WARNING Disk-usage-95%

    의미: -n은 몇 번째 줄에서 찾았는지 줄번호를 함께 보여줍니다. 나중에 그 줄을 직접 수정하러 갈 때 유용합니다.

  5. $ grep -v "INFO" server.log
2026-08-20 09:15:30 WARNING Disk-usage-80%
2026-08-20 09:20:11 ERROR Connection-timeout
2026-08-20 10:01:00 ERROR Out-of-memory
2026-08-20 11:00:00 WARNING Disk-usage-95%

    의미: -v는 정반대로 동작합니다 — "INFO가 없는 줄만" 보여줍니다. 정상 로그를 걷어내고 이상 신호만 남길 때 씁니다.

  6. $ grep "^apple" fruits.txt
apple,5,1200

    의미: ^는 "줄의 맨 앞"이라는 뜻의 기호입니다. "apple로 시작하는 줄"만 찾을 때 씁니다 (뒤에 apple이 껴있는 경우는 제외).

  7. $ grep -w "fig" fruits.txt
fig,2,2200

    의미: -w는 "정확히 이 단어와 일치할 때만" 찾습니다. 예를 들어 "fig"가 "config" 같은 다른 단어의 일부로 들어있어도 매칭되지 않습니다.

  8. $ grep -l "ERROR" server.log fruits.txt
server.log

    의미: 여러 파일을 동시에 검색할 때, -l은 매칭된 내용이 아니라 매칭이 있었던 파일 이름만 보여줍니다.

  9. $ grep -A1 "ERROR" server.log
2026-08-20 09:20:11 ERROR Connection-timeout
2026-08-20 09:20:15 INFO Retrying-connection
--
2026-08-20 10:01:00 ERROR Out-of-memory
2026-08-20 10:01:05 INFO Process-restarted

    의미: -A1(After)은 매칭된 줄 다음 1줄까지 함께 보여줍니다. "에러 다음에 시스템이 뭘 했는지" 확인할 때 유용합니다.

  10. $ grep -B1 "ERROR" server.log
2026-08-20 09:15:30 WARNING Disk-usage-80%
2026-08-20 09:20:11 ERROR Connection-timeout
--
2026-08-20 09:20:20 INFO Connection-restored
2026-08-20 10:01:00 ERROR Out-of-memory

    의미: -B1(Before)은 반대로 매칭된 줄 바로 앞 1줄을 함께 보여줍니다. "에러 직전에 무슨 경고가 있었는지" 확인할 때 씁니다.

grep · 어려움 10제

  1. $ grep -E "ERROR|WARNING" server.log
2026-08-20 09:15:30 WARNING Disk-usage-80%
2026-08-20 09:20:11 ERROR Connection-timeout
2026-08-20 10:01:00 ERROR Out-of-memory
2026-08-20 11:00:00 WARNING Disk-usage-95%

    의미: -E는 정규식(패턴 문법)을 더 쓸 수 있게 해줍니다. |는 "또는(OR)"이라는 뜻 — "ERROR 이거나 WARNING인 줄"을 한 번에 찾습니다.

  2. $ grep -E "^[0-9]{4}-[0-9]{2}-[0-9]{2}" server.log | wc -l
10

    의미: [0-9]{4}는 "숫자가 정확히 4개"라는 뜻입니다. "YYYY-MM-DD" 날짜 형식으로 시작하는 줄만 찾는 패턴이며, 여기선 모든 줄이 이 형식이라 10줄 전부 매칭됩니다.

  3. $ grep -oE "[0-9]{2}:[0-9]{2}:[0-9]{2}" server.log
09:01:12
09:03:45
09:15:30
...(생략)...

    의미: -o는 매칭된 줄 전체가 아니라 매칭된 부분만 잘라서 보여줍니다. 정규식과 함께 쓰면 "시간 부분만 쏙 뽑기" 같은 작업이 가능합니다.

  4. $ grep -c -E "^[0-9]{4}-[0-9]{2}-[0-9]{2} 10:" server.log
2

    의미: "10시대에 발생한 로그가 몇 줄인지"를 정규식(시간 패턴)과 -c(개수 세기)를 조합해 한 번에 계산합니다.

  5. $ grep -rn "ERROR" ~/kdt-linux/cmd-practice
server.log:4:2026-08-20 09:20:11 ERROR Connection-timeout
server.log:7:2026-08-20 10:01:00 ERROR Out-of-memory

    의미: -r은 폴더 안의 모든 하위 폴더까지 재귀적으로 검색합니다. 파일이 여러 개·여러 폴더에 흩어져 있을 때 표준적으로 쓰는 방식입니다.

  6. $ grep -v -E "INFO|WARNING" server.log
2026-08-20 09:20:11 ERROR Connection-timeout
2026-08-20 10:01:00 ERROR Out-of-memory

    의미: -v(제외)와 -E(OR 패턴)를 합치면 "INFO도 아니고 WARNING도 아닌 줄", 즉 ERROR만 남길 수 있습니다.

  7. $ grep -E ",[0-9]{4}$" fruits.txt
apple,5,1200
cherry,3,5000
date,0,3000
elderberry,7,4500
fig,2,2200
honeydew,1,3500

    의미: $는 "줄의 맨 끝", [0-9]{4}는 "숫자 4자리"입니다. 즉 "가격이 정확히 4자리 숫자인 줄"만 골라냅니다. 3자리 가격(banana 800원 등)은 제외됩니다.

  8. $ printf "apple\ngrape\n" > keywords.txt
$ grep -f keywords.txt fruits.txt
apple,5,1200
grape,15,900

    의미: -f 파일명은 검색어를 명령줄에 직접 쓰지 않고 파일에 목록으로 저장해서 한 번에 검색합니다. 클래스 이름이 10개, 20개로 많아지는 실무 검수 작업에서 자주 쓰입니다.

  9. $ grep -m1 "INFO" server.log
2026-08-20 09:01:12 INFO Server-started

    의미: -m1(max-count)은 매칭이 여러 개 있어도 맨 처음 1개만 찾고 바로 멈춥니다. 파일이 수백만 줄이어도 즉시 결과를 돌려주기 때문에 대용량 로그에서 유용합니다.

  10. $ grep -P '(?<=usage-)\d+' server.log
80
95

    의미: -P는 파이썬 스타일의 강력한 정규식을 쓸 수 있게 해줍니다. (?<=usage-)는 "usage- 라는 글자 바로 뒤"라는 위치 조건이고, \d+는 그 뒤에 오는 숫자만 뽑아냅니다 — 즉 "80%"·"95%"에서 숫자만 추출합니다.

2. sed — 줄 단위로 바꾸고 지우기

sed는 파일 내용을 화면에 출력하면서 동시에 바꿔주는 명령어입니다. 파일을 열지 않고도 "이 단어를 저 단어로 바꿔줘", "이 줄은 지워줘" 같은 작업을 한 줄 명령으로 처리합니다.

sed · 쉬움 10제

  1. $ sed 's/apple/APPLE/' fruits.txt
APPLE,5,1200
banana,10,800
...(이하 동일)...

    의미: s/찾을말/바꿀말/ 형태가 sed 치환의 기본형입니다. apple이 있는 줄에서만 바뀌고, 나머지 줄은 그대로 출력됩니다.

  2. $ sed 's/,/ : /' fruits.txt
apple : 5,1200
banana : 10,800
...(이하 동일)...

    의미: 기본적으로 sed는 한 줄에서 처음 매칭된 것 1개만 바꿉니다. 그래서 콤마가 2개 있어도 첫 번째 콤마만 " : "로 바뀝니다.

  3. $ sed 's/,/ : /g' fruits.txt
apple : 5 : 1200
banana : 10 : 800
...(이하 동일)...

    의미: 맨 뒤에 g(global) 플래그를 붙이면 "한 줄에 있는 모든 매칭"을 바꿉니다. 콤마 2개가 전부 " : "로 바뀝니다.

  4. $ sed -n '2p' fruits.txt
banana,10,800

    의미: -n은 "자동으로 전체 출력하지 마"라는 옵션이고, 2p는 "2번째 줄만 출력(print)해"라는 뜻입니다. 둘을 같이 써야 원하는 줄만 깔끔하게 볼 수 있습니다.

  5. $ sed -n '1,3p' fruits.txt
apple,5,1200
banana,10,800
cherry,3,5000

    의미: 1,3p처럼 범위를 지정하면 1번째부터 3번째 줄까지 출력합니다. 큰 파일의 앞부분만 보고 싶을 때 head 대신 쓸 수 있습니다.

  6. $ sed '2d' fruits.txt
apple,5,1200
cherry,3,5000
date,0,3000
...(이하 동일)...

    의미: d는 삭제(delete)입니다. 2d는 "2번째 줄을 삭제하고 나머지를 출력해"라는 뜻입니다. 원본 파일은 바뀌지 않고 화면 출력만 바뀝니다.

  7. $ sed '/ERROR/d' server.log
2026-08-20 09:01:12 INFO Server-started
2026-08-20 09:03:45 INFO User-login:kdt01
2026-08-20 09:15:30 WARNING Disk-usage-80%
...(ERROR 줄만 빠지고 나머지 출력)...

    의미: 줄 번호 대신 패턴으로 삭제할 줄을 지정할 수 있습니다. "ERROR가 포함된 줄을 전부 삭제"하는 매우 실용적인 패턴입니다.

  8. $ sed '1i\맨위에추가된줄' fruits.txt
맨위에추가된줄
apple,5,1200
...(이하 동일)...

    의미: i(insert)는 지정한 줄 앞에 새 텍스트를 끼워 넣습니다. 1i는 "1번째 줄 앞에 삽입"이라는 뜻입니다.

  9. $ sed '$a\맨아래에추가된줄' fruits.txt
apple,5,1200
...(중간 생략)...
lemon,20,300
맨아래에추가된줄

    의미: $는 "맨 마지막 줄"을 의미하는 기호이고, a(append)는 그 뒤에 새 텍스트를 추가합니다.

  10. $ sed 's/error/[에러발견]/I' server.log
...
2026-08-20 09:20:11 [에러발견] Connection-timeout
...
2026-08-20 10:01:00 [에러발견] Out-of-memory
...

    의미: 파일에는 대문자 "ERROR"만 있는데 소문자 "error"로 검색해도 바뀝니다. /I 플래그는 치환할 때 대소문자를 구분하지 않겠다는 뜻입니다.

sed · 어려움 10제

  1. $ sed -E 's/([a-z]+),([0-9]+),([0-9]+)/\1 - \2개 - \3원/' fruits.txt
apple - 5개 - 1200원
banana - 10개 - 800원
...(이하 동일)...

    의미: 괄호 ()로 감싼 부분을 "그룹"이라 하고, 각각 \1 \2 \3으로 재사용할 수 있습니다. 콤마로 구분된 값을 원하는 문장 형태로 재조립할 때 씁니다.

  2. $ sed -i.bak 's/INFO/INFO_LOG/g' server.log
$ ls server.log*
server.log  server.log.bak

    의미: -i는 화면 출력 대신 파일 자체를 직접 수정합니다. .bak을 붙이면 수정 전 원본이 server.log.bak으로 자동 백업됩니다 — 실수했을 때 되돌릴 안전장치입니다.

  3. $ sed -n '/ERROR/,+1p' server.log
2026-08-20 09:20:11 ERROR Connection-timeout
2026-08-20 09:20:15 INFO Retrying-connection
2026-08-20 10:01:00 ERROR Out-of-memory
2026-08-20 10:01:05 INFO Process-restarted

    의미: /패턴/,+1p는 "패턴이 매칭된 줄부터 그 다음 1줄까지" 출력합니다. grep의 -A1과 비슷한 효과를 sed로 낸 것입니다.

  4. $ sed -n '/WARNING/,/ERROR/p' server.log
2026-08-20 09:15:30 WARNING Disk-usage-80%
2026-08-20 09:20:11 ERROR Connection-timeout

    의미: 시작 패턴과 끝 패턴을 둘 다 지정하면 "그 구간에 있는 줄들"을 출력합니다. 로그에서 "경고가 뜨고 나서 에러가 나기까지" 구간만 뽑아낼 때 유용합니다.

  5. $ sed -E '/^([0-9]{4})-([0-9]{2})-([0-9]{2})/s//\3\/\2\/\1/' server.log | head -2
20/08/2026 09:01:12 INFO Server-started
20/08/2026 09:03:45 INFO User-login:kdt01

    의미: 날짜 형식을 "YYYY-MM-DD"에서 "DD/MM/YYYY"로 통째로 바꿉니다. 그룹 \1\2\3의 순서를 재배치하는 실무형 날짜 변환 패턴입니다.

  6. $ sed '3,5s/,/ | /g' fruits.txt
apple,5,1200
banana,10,800
cherry | 3 | 5000
date | 0 | 3000
elderberry | 7 | 4500
fig,2,2200
...(이하 동일)...

    의미: 3,5(줄 범위)와 s/,/ | /g(치환)를 붙여 쓰면 "3~5번째 줄에서만" 치환이 적용됩니다. 나머지 줄은 원본 그대로입니다.

  7. $ sed '/WARNING/{s/95%/[심각]95%/}' server.log | tail -1
2026-08-20 11:00:00 WARNING Disk-usage-[심각]95%

    의미: 중괄호 {}는 "WARNING이 있는 줄에서만" 안에 적힌 치환 규칙을 적용하겠다는 조건문입니다. 다른 WARNING 줄(80%)은 조건에 안 맞아 바뀌지 않습니다.

  8. $ printf 'a   b\tc  d\n' | sed -E 's/[ \t]+/,/g'
a,b,c,d

    의미: [ \t]+는 "공백이나 탭이 1개 이상 연속"이라는 뜻입니다. 사람이 손으로 만들어 공백이 제각각인 파일을 콤마 구분자로 깔끔하게 통일할 때 씁니다.

  9. $ sed 's/[0-9]\{4\}/[&]/' fruits.txt
apple,5,[1200]
banana,10,800
cherry,3,[5000]
...(4자리 숫자만 대괄호로 감싸짐)...

    의미: &는 "방금 매칭된 문자열 그 자체"를 다시 쓸 수 있는 특수 기호입니다. 값을 직접 타이핑하지 않고도 매칭된 부분을 감싸거나 꾸밀 수 있습니다.

  10. $ sed -e 's/apple/사과/' -e 's/banana/바나나/' -e 's/cherry/체리/' fruits.txt
사과,5,1200
바나나,10,800
체리,3,5000
...(이하 동일)...

    의미: -e를 여러 번 쓰면 한 번의 명령 실행으로 여러 치환 규칙을 순서대로 적용합니다. 파이프(|)로 sed를 여러 번 연결하지 않아도 됩니다.

3. awk — 표 형태 데이터 계산하기

awk는 파일을 여러 개의 열(컬럼)로 나눠서 다루는 명령어입니다. 콤마·공백으로 구분된 데이터에서 특정 열만 뽑거나, 숫자를 더하고 평균 내는 계산기 역할을 합니다.

awk · 쉬움 10제

  1. $ awk '{print $1, $2}' server.log
2026-08-20 09:01:12
2026-08-20 09:03:45
...(이하 동일)...

    의미: awk는 한 줄을 공백 기준으로 $1(첫 번째 값), $2(두 번째 값)…으로 자동으로 나눕니다. 원하는 열번호만 골라 출력할 수 있습니다.

  2. $ awk '{print $3}' server.log
INFO
INFO
WARNING
...(이하 동일)...

    의미: 3번째 열, 즉 로그 레벨(INFO/WARNING/ERROR)만 뽑아냅니다. 필요한 열 하나만 볼 때 $숫자를 바꿔가며 씁니다.

  3. $ awk '{print NR, $0}' fruits.txt
1 apple,5,1200
2 banana,10,800
...(이하 동일)...

    의미: NR은 "지금 몇 번째 줄을 처리 중인지" 자동으로 세어주는 내장 변수입니다. $0은 "줄 전체"를 의미합니다.

  4. $ awk -F',' '{print $1}' fruits.txt
apple
banana
cherry
...(이하 동일)...

    의미: -F','는 "이 파일은 공백이 아니라 콤마로 열이 나뉜다"고 알려주는 옵션입니다. fruits.txt처럼 CSV 형태 파일을 다룰 땐 반드시 필요합니다.

  5. $ awk -F',' '{print $1, $3}' fruits.txt
apple 1200
banana 800
...(이하 동일)...

    의미: 콤마로 구분하고 나서, 1번째(과일명)와 3번째(가격) 열만 골라 출력합니다. 필요 없는 열(수량)은 그냥 건너뜁니다.

  6. $ awk -F',' '{print NF}' fruits.txt
3
3
3
...(모든 줄이 3)...

    의미: NF는 "지금 줄에 열이 몇 개 있는지" 알려줍니다. fruits.txt는 모든 줄이 "이름,수량,가격" 3개 열이라 전부 3이 나옵니다.

  7. $ awk '/ERROR/' server.log
2026-08-20 09:20:11 ERROR Connection-timeout
2026-08-20 10:01:00 ERROR Out-of-memory

    의미: 뒤에 실행할 동작({})을 생략하면 awk는 자동으로 "매칭된 줄을 그대로 출력"합니다. 이 경우 grep과 거의 똑같이 동작합니다.

  8. $ awk -F',' '{sum += $2} END {print sum}' fruits.txt
71

    의미: sum += $2는 "각 줄의 2번째 값(수량)을 sum이라는 변수에 계속 더해라"는 뜻이고, END{}는 "모든 줄을 다 읽고 난 뒤 딱 한 번" 실행됩니다. 전체 수량의 합계(71)를 구합니다.

  9. $ awk -F',' '{print $1 "의 가격은 " $3 "원"}' fruits.txt
apple의 가격은 1200원
banana의 가격은 800원
...(이하 동일)...

    의미: 열 값과 직접 쓴 문자열을 나란히 이어붙이면 원하는 문장 형태로 출력을 꾸밀 수 있습니다.

  10. $ awk 'END {print NR}' fruits.txt
10

    의미: 매 줄마다 하는 일 없이 END에서만 NR(총 처리한 줄 수)을 출력하면, "파일이 총 몇 줄인지" 셀 수 있습니다 (wc -l과 같은 효과).

awk · 어려움 10제

  1. $ awk -F',' '$2 > 5 {print $1}' fruits.txt
banana
elderberry
grape
honeydew
kiwi
lemon

    의미: $2 > 5는 "2번째 값(수량)이 5보다 큰 줄만"이라는 조건입니다. 조건을 만족하는 줄에서만 {print $1}이 실행됩니다.

  2. $ awk -F',' '{ if ($3 >= 3000) print $1, "고가"; else print $1, "저가" }' fruits.txt
apple 저가
banana 저가
cherry 고가
date 고가
elderberry 고가
fig 저가
grape 저가
honeydew 고가
kiwi 저가
lemon 저가

    의미: if(조건) A; else B 구조로 각 줄을 조건에 따라 두 그룹으로 분류합니다. 가격이 3000원 이상이면 "고가", 아니면 "저가"를 붙입니다.

  3. $ awk -F',' '{sum+=$3; cnt++} END {print "평균가격:", sum/cnt}' fruits.txt
평균가격: 2340

    의미: 가격 합계(sum)와 줄 개수(cnt)를 동시에 누적한 뒤, 마지막에 나눗셈으로 평균을 계산합니다.

  4. $ awk -F',' '{price[$1]=$3} END {for (f in price) print f, price[f]}' fruits.txt
apple 1200
banana 800
...(순서는 실행할 때마다 달라질 수 있음)...

    의미: price[$1]=$3는 "과일 이름을 키로, 가격을 값으로" 저장하는 연관배열입니다. for (f in price)로 저장된 모든 키를 순회하며 꺼내볼 수 있습니다.

  5. $ awk -F',' 'BEGIN {print "과일,수량,가격"} {print}' fruits.txt
과일,수량,가격
apple,5,1200
banana,10,800
...(이하 동일)...

    의미: BEGIN{}은 파일을 읽기 전에 딱 한 번 실행됩니다. 표 맨 위에 헤더(제목 줄)를 붙일 때 이런 방식을 씁니다.

  6. $ awk '{split($1,d,"-"); print d[2]}' server.log
08
08
08
...(모든 줄에서 "08")...

    의미: split(문자열,배열,구분자)는 문자열을 구분자로 잘라 배열에 담습니다. "2026-08-20"을 "-"로 쪼개면 d[1]=2026, d[2]=08, d[3]=20이 되어 월(月)만 뽑을 수 있습니다.

  7. $ awk '/ERROR/{c++} END{print "ERROR 총", c+0, "건"}' server.log
ERROR 총 2 건

    의미: ERROR가 있는 줄을 만날 때마다 카운터 c를 하나씩 늘리고, 마지막에 총 개수를 요약해서 보여줍니다. 로그 집계 리포트의 기본 패턴입니다.

  8. $ awk -F',' '{gsub("e","E",$1); print $1}' fruits.txt
applE
banana
chErry
datE
EldErbErry
...(이하 동일)...

    의미: gsub(찾을글자,바꿀글자,대상)는 sed의 s///g와 같은 역할을 awk 안에서 합니다. 여기서는 과일 이름의 모든 'e'를 'E'로 바꿉니다.

  9. $ awk -F',' '{printf "%-12s %5d개 %6d원\n", $1, $2, $3}' fruits.txt
apple           5개   1200원
banana         10개    800원
cherry          3개   5000원
...(열이 가지런히 정렬됨)...

    의미: printf는 %-12s(왼쪽정렬, 12칸), %5d(오른쪽정렬 숫자, 5칸)처럼 자릿수를 지정해 표처럼 가지런한 출력을 만듭니다. 보고서나 통계표를 만들 때 필수입니다.

  10. $ awk -F',' '$2==0 {print $1, "재고없음"}' fruits.txt
date 재고없음

    의미: $2==0은 "수량이 정확히 0인 줄만"이라는 조건입니다. 재고가 바닥난 항목을 자동으로 찾아 경고 메시지를 만드는 실무형 예제입니다.

4. vim — 편집기 안에서 명령으로 편집하기

vim은 grep·sed·awk와 달리 화면을 보면서 직접 편집하는 도구입니다. 아래 예제는 "어떤 상태에서 → 어떤 키를 누르면 → 어떻게 바뀌는지"를 순서대로 보여줍니다. vim sample.txt로 실행한 뒤 하나씩 따라 해 보세요.

vim · 쉬움 10제

  1. $ vim sample.txt 실행
결과: apple/banana/cherry/date/elderberry 5줄이 화면에 보이고, 아직 아무것도 입력할 수 없는 상태(Normal 모드)로 시작됨

    의미: vim은 열자마자 바로 타이핑되는 게 아니라, "명령을 내리는 대기 상태(Normal 모드)"로 시작합니다.

  2. 입력: i
결과: 화면 맨 아래에 "-- INSERT --" 표시가 뜨고, 이제 글자를 입력할 수 있는 상태로 바뀜

    의미: i(insert)는 "지금 커서 위치에서부터 글자를 입력하겠다"는 명령입니다.

  3. 입력: Esc
결과: "-- INSERT --" 표시가 사라지고 다시 Normal 모드로 돌아감

    의미: 입력을 끝냈으면 반드시 Esc로 빠져나와야 다른 명령(저장·이동 등)을 내릴 수 있습니다.

  4. 입력: :wq (Enter)
결과: 수정한 내용이 저장되고 vim이 종료되어 셸 프롬프트로 돌아옴

    의미: w는 저장(write), q는 종료(quit)입니다. 둘을 붙여 쓰면 "저장하고 나가기"가 됩니다.

  5. 입력: :q! (Enter)
결과: 수정한 내용을 저장하지 않고 강제로 종료됨

    의미: !는 "묻지 말고 강제로 실행"이라는 뜻입니다. 실수로 건드린 내용을 버리고 싶을 때 씁니다.

  6. 상황: 커서가 2번째 줄(banana)에 있음
입력: dd
결과: banana 줄이 통째로 삭제되고, 나머지 줄이 한 칸씩 위로 당겨짐

    의미: dd는 "커서가 있는 줄 전체를 삭제"하는 명령입니다.

  7. 상황: 방금 dd로 banana를 삭제한 직후
입력: p
결과: 삭제했던 banana 줄이 커서 아래에 다시 나타남

    의미: p(paste)는 방금 삭제하거나 복사한 내용을 다시 붙여넣습니다. dd 다음에 바로 쓰면 "잘라내기 후 붙여넣기"가 됩니다.

  8. 상황: 커서가 3번째 줄(cherry)에 있고 커서를 맨 아래(elderberry)로 옮긴 상태
입력: (cherry줄에서) yy → (맨아래로 이동) → p
결과: cherry 줄이 원본은 그대로 둔 채 맨 아래에 복사되어 추가됨

    의미: yy(yank)는 삭제 없이 복사만 합니다. dd(잘라내기)와 정확히 반대되는 개념입니다.

  9. 입력: /date (Enter)
결과: 커서가 "date"라는 글자가 있는 줄로 즉시 이동함

    의미: /찾을말은 파일 안에서 원하는 단어를 검색해 그 위치로 이동합니다. 긴 파일에서 특정 단어를 찾을 때 Ctrl+F(브라우저 찾기)와 비슷한 역할입니다.

  10. 상황: 방금 dd로 한 줄을 삭제한 직후
입력: u
결과: 삭제하기 전 상태로 되돌아감(삭제했던 줄이 복원됨)

    의미: u(undo)는 마지막 작업을 취소합니다. 여러 번 누르면 계속 더 이전 상태로 돌아갈 수 있습니다.

vim · 어려움 10제

  1. 입력: :%s/a/A/g (Enter)
결과: 파일 전체에서 모든 소문자 'a'가 'A'로 바뀜 (apple→Apple, banana→bAnAnA, date→dAte 등)

    의미: %는 "파일 전체 줄"이라는 뜻이고, sed에서 배운 s/.../.../g를 그대로 씁니다. vim 안에서 sed와 똑같은 방식으로 전체 치환을 할 수 있습니다.

  2. 입력: :2,4d (Enter)
결과: 2번째부터 4번째 줄(banana, cherry, date)이 한 번에 삭제되고 apple, elderberry만 남음

    의미: 2,4로 범위를 지정한 뒤 d(삭제)를 붙이면, 여러 줄을 dd를 여러 번 누르지 않고 한 번에 지울 수 있습니다.

  3. 입력: :g/a/d (Enter)
결과: 'a'가 포함된 모든 줄(apple, banana, date)이 삭제되고 cherry, elderberry만 남음

    의미: g/패턴/d는 "패턴에 맞는 모든 줄을 찾아서 삭제"합니다. sed의 /pattern/d를 vim 안에서 실행하는 것과 같습니다.

  4. 상황: 5줄 모두 맨 앞에 "- "를 붙이고 싶을 때
입력: Ctrl+v → 5줄 전체 선택 → I → "- " 입력 → Esc
결과: 5줄 전부의 맨 앞에 "- "가 동시에 삽입됨

    의미: Ctrl+v는 비주얼 블록 모드입니다. 여러 줄의 같은 위치를 한 번에 편집할 때 씁니다 (예: 여러 줄 주석 처리).

  5. 입력: qa → (원하는 편집 동작 수행) → q
결과: 방금 한 편집 동작이 "a"라는 이름의 매크로로 저장됨 (화면엔 "recording" 표시가 떴다 사라짐)

    의미: qa는 "지금부터 하는 동작을 a라는 이름으로 녹화 시작"이고, 마지막 q는 "녹화 종료"입니다.

  6. 상황: 위에서 매크로 a를 저장한 직후
입력: 5@a
결과: 저장해둔 매크로 a의 동작이 연속으로 5번 반복 실행됨

    의미: @매크로이름은 저장된 매크로를 재생하고, 앞에 숫자를 붙이면 그 횟수만큼 반복합니다. 똑같은 편집을 수십 줄에 반복해야 할 때 매우 강력합니다.

  7. 입력: :set number (Enter)
결과: 화면 왼쪽에 1,2,3,4,5 줄번호가 표시됨

    의미: :set 옵션이름은 vim의 화면/동작 설정을 바꿉니다. 줄번호를 켜두면 :2,4d 같은 범위 명령을 쓸 때 훨씬 편합니다.

  8. 입력: :v/cherry/d (Enter)
결과: "cherry"가 없는 모든 줄이 삭제되고 cherry 줄만 남음

    의미: v는 g의 반대(invert)입니다. "패턴에 매칭되지 않는 줄"에 대해 명령을 실행합니다.

  9. 상황: 커서가 "banana"라는 단어 위에 있음
입력: ciw → "MANGO" 입력 → Esc
결과: banana가 통째로 지워지고 그 자리에 MANGO로 바뀜

    의미: c(change)+iw(inner word)는 "커서가 있는 단어 하나를 통째로 바꾼다"는 뜻입니다. 단어 하나만 빠르게 고칠 때 dd+i보다 훨씬 빠릅니다.

  10. 입력: :r! ls (Enter)
결과: 현재 폴더에서 ls 명령을 실행한 결과(파일 목록)가 커서 위치에 그대로 삽입됨

    의미: :r!셸명령은 vim 밖의 셸 명령을 실행한 결과를 파일 안에 바로 가져옵니다. 스크립트 틀을 자동으로 채워 넣을 때 활용됩니다.

5. nano — 핵심 단축키 10개

nano는 vim과 달리 "모드 전환"이 없는 아주 단순한 편집기입니다. 화면 아래 안내된 단축키(^는 Ctrl을 의미)만 누르면 되기 때문에, 어려운 예제를 따로 만들기보다 꼭 필요한 10개를 표로 정리했습니다.

번호단축키예상 결과의미
1nano 파일명해당 파일이 바로 화면 가득 열리고 즉시 글자를 입력할 수 있는 상태vim과 달리 모드 구분 없이 열자마자 바로 편집 가능
2Ctrl+O화면 아래 "File Name to Write:"가 뜨고, Enter를 누르면 저장됨O = "Write Out", 저장하기
3Ctrl+X편집기가 종료되고 셸 프롬프트로 복귀(저장 안 했으면 저장할지 물어봄)X = 종료(eXit)
4Ctrl+K커서가 있는 줄 전체가 잘라내어 사라짐K = 잘라내기(Kut), vim의 dd와 같은 역할
5Ctrl+U방금 Ctrl+K로 잘라낸 줄이 커서 위치에 다시 붙여넣어짐U = 붙여넣기(Uncut), vim의 p와 같은 역할
6Ctrl+W화면 아래 "Search:"가 뜨고, 검색어 입력 후 Enter하면 그 위치로 이동W = 검색(Where is)
7Ctrl+\"Search (to replace):"가 뜨고, 찾을 말→바꿀 말을 순서대로 입력해 치환찾아 바꾸기(Replace) — sed의 s/// 를 대화형으로 하는 셈
8Ctrl+G사용 가능한 모든 단축키 목록(도움말) 화면이 뜸G = 도움말(Get Help), 단축키가 기억 안 날 때 확인
9Ctrl+_ 후 줄번호 입력"Enter line number"에 숫자를 입력하면 그 줄로 즉시 이동특정 줄번호로 바로 점프(vim의 :숫자와 같은 역할)
10Alt+U방금 한 마지막 편집이 취소되고 이전 상태로 돌아감실행 취소(Undo), vim의 u와 같은 역할
