1교시 · 셸 스크립트 기초 (50분)

1.1 왜 스크립트를 짜는가

3일차에 우리가 친 명령을 떠올려 봅시다.

ls *.jpg | sed 's/\.jpg$//' | sort > /tmp/imgs.txt
ls *.txt | sed 's/\.txt$//' | sort > /tmp/lbls.txt
comm -23 /tmp/imgs.txt /tmp/lbls.txt
awk 'NF!=5 && NF!=0 {print FILENAME}' *.txt
find . -name "*.txt" -size 0
...

교과 8에서 한 번, 교과 14에서 팀마다 한 번, 데이터 갱신할 때마다 또 한 번. 같은 명령을 20번 치는 대신 한 번 만들어 20번 실행합니다.

평가항목 「코드 품질 — 재사용성」이 여기서 갈립니다.

1.2 최소 골격

#!/bin/bash
# 설명 주석
set -euo pipefail

echo "Hello"
요소 의미
#!/bin/bash shebang. 이 파일을 bash로 실행하라
set -e 명령이 실패하면 즉시 중단
set -u 정의 안 된 변수 사용 시 에러
set -o pipefail 파이프 중간 실패도 감지

set -euo pipefail 은 셸 스크립트의 "안전벨트"입니다. 없으면 에러가 나도 스크립트가 계속 진행해서 잘못된 결과를 만듭니다.

2교시 · 조건·반복·함수 (50분)

2.1 조건문

if [ 조건 ]; then
    ...
elif [ 조건 ]; then
    ...
else
    ...
fi

파일 테스트 (실무 최다 사용)

연산자 의미
-f 파일 일반 파일로 존재
-d 경로 디렉토리로 존재
-e 경로 존재 (종류 무관)
-s 파일 존재하고 크기 > 0
-r -w -x 읽기/쓰기/실행 가능
-L 심볼릭 링크

숫자/문자열 비교

숫자 문자열
-eq -ne = !=
-lt -le < (\<)
-gt -ge > (\>)
-z 비어있음 / -n 안 비어있음 
if [ ! -d "$DATA_DIR" ]; then
    echo "ERROR: $DATA_DIR 없음" >&2
    exit 1
fi

if [ "$COUNT" -lt 500 ]; then
    echo "WARN: 최소 500장 요건 미달 ($COUNT장)"
fi

[[ ]] 는 bash 확장으로 더 안전합니다(&&, ||, 패턴 매칭 지원). 본 과정은 [ ] 기본형과 [[ ]]를 병행 소개합니다.

2.2 반복문

# for — 목록
for f in *.txt; do
    echo "$f"
done

# for — 범위
for i in {1..5}; do echo "$i"; done
for i in $(seq -w 1 100); do echo "img_$i"; done

# while — 파일 한 줄씩 읽기 ★
while read -r line; do
    echo "[$line]"
done < list.txt

# 무한 루프 + break
while true; do
    ...
    [ 조건 ] && break
done

read -r 의 -r 은 백슬래시를 그대로 읽으라는 뜻입니다. 경로에 \가 들어갈 수 있으므로 항상 붙입니다.

2.3 case

case "$1" in
    check)  do_check ;;
    split)  do_split ;;
    report) do_report ;;
    *)      echo "사용법: $0 {check|split|report}"; exit 1 ;;
esac

2.4 함수

log_info () {
    echo "[INFO] $(date '+%H:%M:%S') $*"
}

count_files () {
    local dir="$1"
    local ext="$2"
    find "$dir" -name "*.$ext" | wc -l
}

n=$(count_files "raw" "jpg")
log_info "이미지 $n 장"

local 을 안 쓰면 함수 안 변수가 전역이 되어 다른 함수와 충돌합니다. 반드시 습관화.

3.5 tmux — 현업 표준 ★★

문제 상황: AWS GPU 서버에 SSH로 붙어 12시간짜리 학습을 시작했는데, 노트북을 닫거나 네트워크가 끊기면 → 학습이 죽습니다.

해결: tmux는 서버 안에서 세션을 유지합니다. 접속이 끊겨도 세션은 계속 돌아갑니다.

sudo apt install tmux

tmux new -s train         # 'train' 세션 생성
# ... 학습 실행 ...
# Ctrl+b 누른 뒤 d      → detach (세션 유지하고 나가기)

tmux ls                   # 세션 목록
tmux attach -t train      # 다시 붙기
tmux kill-session -t train
키 (Ctrl+b 후) 기능
d detach
% 세로 분할
" 가로 분할
방향키 창 이동
c 새 윈도우
n / p 다음/이전 윈도우
[ 스크롤 모드 (q로 종료)

현업 사용법: 왼쪽 창에서 학습 실행, 오른쪽 창에서 watch -n1 nvidia-smi로 GPU 모니터링. 교과 5·8·10·11의 모든 장시간 학습이 이 형태입니다.

#!/bin/bash
set -euo pipefail

TARGET="${1:-}"

if [ -z "$TARGET" ]; then
    echo "사용법: $0 <경로>" >&2
    exit 2
fi

if [ -d "$TARGET" ]; then
    echo "[OK] 디렉토리입니다"
    echo "  파일 수: $(ls -1 "$TARGET" | wc -l)"
    echo "  용량:   $(du -sh "$TARGET" | cut -f1)"
elif [ -f "$TARGET" ]; then
    echo "[OK] 파일입니다"
    echo "  크기: $(stat -c%s "$TARGET") bytes"
    echo "  권한: $(stat -c%A "$TARGET")"
else
    echo "[ERROR] 존재하지 않습니다: $TARGET" >&2
    exit 1
fi

chmod +x check_dir.sh

./check_dir.sh /없는경로 ; echo "종료코드=$?"

Step 3. 반복문 연습

vim list_datasets.sh

#!/bin/bash
set -euo pipefail
readonly ROOT=~/kdt-linux/dataset

printf "%-15s %8s %8s %10s\n" "DATASET" "IMAGES" "LABELS" "SIZE"
printf "%-15s %8s %8s %10s\n" "-------" "------" "------" "----"

for ds in "$ROOT"/*/; do
    [ -d "$ds" ] || continue
    name=$(basename "$ds")
    imgs=$(find "$ds" -name "*.jpg" 2>/dev/null | wc -l)
    lbls=$(find "$ds" -name "*.txt" 2>/dev/null | wc -l)
    size=$(du -sh "$ds" 2>/dev/null | cut -f1)
    printf "%-15s %8d %8d %10s\n" "$name" "$imgs" "$lbls" "$size"
done

chmod +x list_datasets.sh && ./list_datasets.sh

cd ~/kdt-linux/scripts

#!/bin/bash
#===============================================================
# 파일명 : dataset_check.sh
# 목적   : Vision AI 데이터셋(YOLO 포맷) 정합성 검증
# 사용법 : ./dataset_check.sh <dataset_dir> [--fix] [--min N]
# 작성일 : 2026-08-29
#===============================================================
set -uo pipefail       # -e 는 검사 중 중단되면 안 되므로 제외

readonly SCRIPT_NAME=$(basename "$0")
MIN_IMAGES=500
DO_FIX=0
ERRORS=0
WARNINGS=0

#---------------------------------------------------------------
usage () {
    cat << EOF
사용법: $SCRIPT_NAME <dataset_dir> [옵션]

인자:
  dataset_dir   검사할 데이터셋 루트 (raw/, meta/classes.txt 포함)

옵션:
  --fix         자동 수정 (빈 라벨 삭제, 공백 파일명 변경)
  --min N       최소 이미지 장수 (기본 $MIN_IMAGES)
  -h, --help    도움말

종료 코드:
  0  PASS
  1  FAIL (오류 발견)
  2  사용법 오류
EOF
}

log ()  { echo "  $*"; }
ok ()   { echo "  [OK]   $*"; }
warn () { echo "  [WARN] $*"; WARNINGS=$((WARNINGS+1)); }
err ()  { echo "  [FAIL] $*"; ERRORS=$((ERRORS+1)); }
section () { echo ""; echo "[$1] $2"; }

#---------------------------------------------------------------
parse_args () {
    [ $# -eq 0 ] && { usage; exit 2; }
    DATASET_DIR="$1"; shift
    while [ $# -gt 0 ]; do
        case "$1" in
            --fix)  DO_FIX=1 ;;
            --min)  shift; MIN_IMAGES="$1" ;;
            -h|--help) usage; exit 0 ;;
            *) echo "알 수 없는 옵션: $1" >&2; usage; exit 2 ;;
        esac
        shift
    done
}

Step 2. 검사 함수 작성

#---------------------------------------------------------------
check_structure () {
    section 1 "디렉토리 구조"
    for d in raw meta; do
        if [ -d "$DATASET_DIR/$d" ]; then ok "$d/ 존재"
        else err "$d/ 없음"; fi
    done
    if [ -f "$DATASET_DIR/meta/classes.txt" ]; then
        NUM_CLASSES=$(grep -c . "$DATASET_DIR/meta/classes.txt")
        ok "classes.txt 존재 (${NUM_CLASSES}종)"
    else
        err "meta/classes.txt 없음"
        NUM_CLASSES=0
    fi
}

check_pairing () {
    section 2 "이미지-라벨 짝 검증"
    local raw="$DATASET_DIR/raw"
    IMG_COUNT=$(find "$raw" -maxdepth 1 -name "*.jpg" | wc -l)
    LBL_COUNT=$(find "$raw" -maxdepth 1 -name "*.txt" | wc -l)
    log "이미지 ${IMG_COUNT}장 / 라벨 ${LBL_COUNT}개"

    find "$raw" -maxdepth 1 -name "*.jpg" -exec basename {} .jpg \; | sort > /tmp/_i.$$
    find "$raw" -maxdepth 1 -name "*.txt" -exec basename {} .txt \; | sort > /tmp/_l.$$

    local no_lbl no_img
    no_lbl=$(comm -23 /tmp/_i.$$ /tmp/_l.$$ | wc -l)
    no_img=$(comm -13 /tmp/_i.$$ /tmp/_l.$$ | wc -l)

    if [ "$no_lbl" -eq 0 ]; then ok "라벨 누락 없음"
    else
        warn "라벨 없는 이미지 ${no_lbl}건"
        comm -23 /tmp/_i.$$ /tmp/_l.$$ | head -5 | sed 's/^/         - /'
    fi

    if [ "$no_img" -eq 0 ]; then ok "이미지 누락 없음"
    else
        err "이미지 없는 라벨 ${no_img}건"
        comm -13 /tmp/_i.$$ /tmp/_l.$$ | head -5 | sed 's/^/         - /'
    fi
    rm -f /tmp/_i.$$ /tmp/_l.$$
}

check_label_format () {
    section 3 "라벨 포맷 검증"
    local raw="$DATASET_DIR/raw"

    # 빈 파일
    local empty
    empty=$(find "$raw" -maxdepth 1 -name "*.txt" -size 0 | wc -l)
    if [ "$empty" -eq 0 ]; then ok "빈 라벨 없음"
    else
        warn "빈 라벨 파일 ${empty}건"
        if [ "$DO_FIX" -eq 1 ]; then
            find "$raw" -maxdepth 1 -name "*.txt" -size 0 -delete
            log "     → --fix: 삭제 완료"
        fi
    fi

    # 필드 개수
    local badnf
    badnf=$(awk 'NF!=5 && NF!=0 {print FILENAME}' "$raw"/*.txt 2>/dev/null | sort -u | wc -l)
    if [ "$badnf" -eq 0 ]; then ok "필드 개수(5) 정상"
    else err "필드 개수 오류 ${badnf}개 파일"; fi

    # 좌표 범위
    local badrange
    badrange=$(awk '{for(i=2;i<=5;i++) if($i<0||$i>1){print FILENAME; next}}' \
               "$raw"/*.txt 2>/dev/null | sort -u | wc -l)
    if [ "$badrange" -eq 0 ]; then ok "좌표 범위(0~1) 정상"
    else
        err "좌표 범위 초과 ${badrange}개 파일"
        awk '{for(i=2;i<=5;i++) if($i<0||$i>1){print "         - "FILENAME": "$0; next}}' \
            "$raw"/*.txt 2>/dev/null | head -3
    fi

    # 클래스 ID
    if [ "$NUM_CLASSES" -gt 0 ]; then
        local maxc badcls
        maxc=$((NUM_CLASSES-1))
        badcls=$(awk -v m="$maxc" '$1<0 || $1>m {print FILENAME}' \
                 "$raw"/*.txt 2>/dev/null | sort -u | wc -l)
        if [ "$badcls" -eq 0 ]; then ok "클래스 ID(0~${maxc}) 정상"
        else err "미정의 클래스 사용 ${badcls}개 파일"; fi
    fi
}

check_filename () {
    section 4 "파일명 규칙"
    local spaced
    spaced=$(find "$DATASET_DIR/raw" -maxdepth 1 -name "* *" | wc -l)
    if [ "$spaced" -eq 0 ]; then ok "공백 포함 파일명 없음"
    else
        warn "공백 포함 파일명 ${spaced}건"
        if [ "$DO_FIX" -eq 1 ]; then
            find "$DATASET_DIR/raw" -maxdepth 1 -name "* *" | while read -r f; do
                mv "$f" "$(echo "$f" | tr ' ' '_')"
            done
            log "     → --fix: 변경 완료"
        fi
    fi
}

check_volume () {
    section 5 "데이터 규모 요건"
    log "요건: 최소 ${MIN_IMAGES}장"
    if [ "$IMG_COUNT" -ge "$MIN_IMAGES" ]; then ok "충족 (${IMG_COUNT}장)"
    else err "미달 (${IMG_COUNT}장 / ${MIN_IMAGES}장)"; fi
}

show_distribution () {
    section 6 "클래스 분포"
    local raw="$DATASET_DIR/raw"
    local cls="$DATASET_DIR/meta/classes.txt"
    [ -f "$cls" ] || { log "(classes.txt 없음)"; return; }

    awk 'NR==FNR {name[$1]=$2; next} {c[$1]++}
         END {
           for (k=0; k<length(name); k++)
             printf "  %-24s %6d\n", (name[k]?name[k]:"class_"k), (c[k]?c[k]:0)
         }' "$cls" "$raw"/*.txt 2>/dev/null

    local total
    total=$(cat "$raw"/*.txt 2>/dev/null | wc -l)
    log "  ----------------------------------"
    printf "  %-24s %6d\n" "TOTAL bbox" "$total"
}

summary () {
    echo ""
    echo "=============================================="
    printf "  결과: 오류 %d건 / 경고 %d건\n" "$ERRORS" "$WARNINGS"
    if [ "$ERRORS" -eq 0 ]; then
        echo "  판정: PASS ✔"
        echo "=============================================="
        return 0
    else
        echo "  판정: FAIL ✘"
        echo "=============================================="
        return 1
    fi
}

#---------------------------------------------------------------
main () {
    parse_args "$@"
    [ -d "$DATASET_DIR" ] || { echo "경로 없음: $DATASET_DIR" >&2; exit 2; }

    echo "=============================================="
    echo "  Dataset Check :: $(basename "$DATASET_DIR")"
    echo "  $(date '+%Y-%m-%d %H:%M:%S')"
    echo "=============================================="

    check_structure
    check_pairing
    check_label_format
    check_filename
    check_volume
    show_distribution
    summary
}

main "$@"

# 장시간 학습 시뮬레이터
set -u
EPOCHS="${1:-20}"
DELAY="${2:-3}"

echo "[$(date '+%H:%M:%S')] Training started (PID=$$)"

    loss=$(awk -v e="$e" 'BEGIN{printf "%.4f", 2.5/(1+e*0.3)}')

done
echo "[$(date '+%H:%M:%S')] Training finished"

cd ~/kdt-linux/scripts

#!/bin/bash
#===============================================================
# 목적 : 데이터셋 메타정보 자동 백업 + 검증 로그 기록
# cron : 0 2 * * *  /home/$USER/kdt-linux/scripts/auto_backup.sh
#===============================================================
set -uo pipefail

readonly ROOT="$HOME/kdt-linux"
readonly LOGFILE="$ROOT/logs/backup.log"
readonly STAMP=$(date +%Y%m%d_%H%M)
readonly KEEP_DAYS=30

mkdir -p "$ROOT/logs"

log () { echo "[$(date '+%F %T')] $*" >> "$LOGFILE"; }

log "===== 백업 시작 ====="

for ds in "$ROOT"/dataset/*/; do
    [ -d "$ds" ] || continue
    name=$(basename "$ds")
    mkdir -p "$ds/backup"
    out="$ds/backup/${name}_meta_${STAMP}.tar.gz"

    if tar -czf "$out" -C "$ds" meta 2>/dev/null; then
        log "OK  $name -> $(basename "$out") ($(du -h "$out" | cut -f1))"
    else
        log "ERR $name 백업 실패"
    fi

    # 정합성 검사 결과도 함께 기록
    if "$ROOT/scripts/dataset_check.sh" "$ds" > /dev/null 2>&1; then
        log "OK  $name 정합성 PASS"
    else
        log "WARN $name 정합성 FAIL"
    fi
done

deleted=$(find "$ROOT/dataset" -name "*_meta_*.tar.gz" -mtime +$KEEP_DAYS -print -delete | wc -l)
log "오래된 백업 ${deleted}건 삭제"
log "===== 백업 종료 ====="

chmod +x auto_backup.sh
