# Day 6 — Git 기초 (8H)
## 핵심 학습 내용
- Git 3영역 구조 (Working Directory, Staging Area, Repository)
- Conventional Commits 형식 (`feat`, `fix`, `docs`, `refactor`, `chore`, `data`)
- 되돌리기 3단계: `restore`, `reset` (--soft/--mixed/--hard), `revert`, `reflog` (구조선)
- `.gitignore` 의 한계(기추적 파일 미적용)와 `git rm --cached`
- 브랜치 생성(`switch -c`), 머지(`merge --no-ff`), 충돌(Conflict) 수동 해결
- 프로젝트 릴리즈 태그(`git tag -a`)

## 산출물
- 로컬 Git 저장소 (`.git`)
- Conventional Commits 기반 커밋 히스토리
- 충돌 해결 및 브랜치 병합 이력
